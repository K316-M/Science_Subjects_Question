# 教学地图的插画：清单与提示词（给 ChatGPT 等绘图 AI）

教学地图（化学三张：无机／有机／物化）要换上你给的图。这份文件是**给绘图 AI 看的整套材料**：先让它了解项目，再一张一张画。格式照 [OPERATIONS 七](OPERATIONS.md) 里背景图、小精灵的提示词写（用途／尺寸／画风／禁止）。

**一共 47 张，分四批；先做第一批的 5 张「风格锚点」，满意了再往下做。** 不满意就在第一批改到满意，後面三批全部靠它对齐风格。

| 批次 | 内容 | 张数 | 在网站里长在哪里 |
|---|---|---|---|
| 1 风格锚点 | 3 个关卡图标、1 个魔王、1 张封面 | 5 | 先看风格对不对 |
| 2 封面＋魔王 | 另外 2 张封面、另外 8 个魔王 | 10 | 选地图页的卡片；地图上每个小节尽头的「魔王关」 |
| 3 关卡图标 | 其余 28 个关卡的图标 | 28 | 地图上每一关的圆形图标（现在是我画的简易 SVG） |
| 4 小特效 | 星星、闪光、彩带 | 4 | 通关、解锁时弹出来的小东西（动起来由我用 CSS 做） |

**小精灵不用重画**：地图的「你在这里」和起点已经用现成的 `assets/sprite/` 姿势图。

---

## 第 0 步：怎么开始（一次就好）

1. 在 ChatGPT 里开一个**项目**（或新对话），把下面「给绘图 AI 的项目简介」整段贴进去当第一条／项目说明。
2. 同一条里**上传 3 张参考图**：`assets/sprite/idle.webp`、`assets/sprite/happy.webp`（小精灵，画风要对齐它）＋你自己截一张现在的教学地图（让它看到图会放在什么框里）。
3. 做第一批的 5 张。**每张满意後存起来，之後每画一张都把「锚点」（第一批里你最满意的 2～3 张）一起上传当参考**，不要只靠文字——和小精灵一样，这样大小、线条粗细、光线方向才会一致。
4. 对话拉得很长、画风开始跑掉，就把下面「画风段」重新贴一次。

## 给绘图 AI 的项目简介（复制整段）

```
我在做一个给马来西亚独立中学（独中）学生用的理科复习网站，学生年龄约 16 到 18 岁，要考 UEC 统一考试。
网站有生物、化学、物理、高级数学四科，整体是柔和水彩背景加米黄色纸张卡片，右下角有一只 Q 版小精灵当吉祥物（附图：骑着悬浮滑板的小男孩，头顶一只长嫩芽的小史莱姆，腰间挂试管）。
我现在要做「化学教学闯关地图」：像《植物大战僵尸 2》的世界地图——海上漂着一座座小岛，路把岛连起来，学生沿着路一关一关地学，每座岛尽头有一个「魔王关」，打赢可以跳级。共三张地图：无机化学、有机化学、物理化学。
地图上的每一关是路上的一个圆形图标，岛上还要摆一些风景小物件，需要一套画风一致的小插画。你接下来会陆续收到我要的图，请全部保持同一个画风。
这些图会以很小的尺寸显示（关卡图标约 56 到 100 像素），所以要「粗、简单、轮廓一眼就认得出」，不要细碎的小细节。
网站有日间和夜间（深色）两种模式，所以所有图都要是「贴纸」：物体外面包一圈奶白色的粗描边，放在深色背景上也看得清楚。
```

## 画风段（每张提示词都要带着这一段；上面的简介已经说过的话，对话拉长时再贴一次）

```
画风：Q 版、可爱的贴纸插画，和附图的小精灵同一个画风——柔和的赛璐珞上色（只有一层明亮、一层淡淡的暗面），细而清楚的深褐色轮廓线，高光是几个干净的小白点或白色弧线。不要照片感、不要 3D 渲染感、不要粗糙的水彩晕染。
光线：统一从左上方来，不要投影、不要地面、不要光晕。
贴纸边：物体外面包一圈约 6 到 8 像素宽的奶白色（#FBF3DF）粗描边，像裁下来的贴纸。
颜色：以奶白、浅蓝（#9FD3E6）、芥末黄（#E9B44C）、铜黄色金属为底色，再加上「这张图所属地图的主色」：无机＝青绿 #0F766E、有机＝紫色 #7C3AED、物化＝琥珀褐 #B45309。每张图最多再加一两种点缀色。
构图：物体在画面正中，四周各留约 10% 的空白；正面略偏上方的视角；只画一个主体（可以带两三个小配件）。
输出：背景必须是「真正透明」的 PNG（不是画进去的灰白棋盘格）。如果你的工具做不到真透明，就把背景画成纯白色 #FFFFFF，不要有任何阴影或渐层，我自己去背。
禁止：任何文字、字母、数字、化学式、元素符号、刻度；浮水印、边框、签名；不要模仿任何现有的动漫、游戏、电影角色；不要恐怖、血腥的造型。
```

## 生出来不对的时候，直接在同一个对话里回它这句

| 看到的问题 | 回它这句 |
|---|---|
| 和锚点的画风不一样 | 请更贴近我上传的锚点图的线条粗细、上色方式和光线，只换画面内容，其他照锚点。 |
| 细节太多，缩小就看不清 | 请把造型再简化：轮廓更粗、细节只留最重要的两三个，缩到 64 像素也要认得出是什么。 |
| 背景不透明／有灰白棋盘格 | 请把背景改成真正透明的 PNG；如果做不到，就改成纯白色 #FFFFFF，不要棋盘格、不要阴影。 |
| 没有奶白色的贴纸边 | 请在物体外面加一圈约 8 像素宽的奶白色（#FBF3DF）粗描边，像裁下来的贴纸。 |
| 出现文字或数字 | 去掉画面上所有文字、字母和数字（包括屏幕、表盘、路牌上的），其他保持不变。 |
| 物体不在正中间／太满 | 请把物体放在正中间，四周各留约 10% 的空白，其他不变。 |
| 魔王不够凶 | 请让魔王的表情再凶一点：眉毛压得更低、眼神更锐利，嘴角下压或咧嘴露出小尖牙；仍然是 Q 版比例，不要血、不要写实。 |
| 魔王太吓人 | 请把魔王的表情收一点：眼睛更大更圆，眉毛抬高一点，不要血、不要阴影里的暗色，保持 Q 版。 |
| 颜色跑掉 | 颜色只用「画风段」里那几种，加这张图所属地图的主色，其他保持不变。 |
| 用了某个现有角色的样子 | 请不要模仿任何现有的动漫、游戏、电影角色，重新设计一个原创造型。 |

## 画好之後怎么交给我

1. **可以一张图里放好几个**（透明底、各自一圈奶白贴纸边，像批次一那样拼成一张）：整张放进 `source/teach/`，告诉我，我按位置切开；也可以一个一个存、文件名照【】里的名字。
2. 关卡、魔王、特效、风景贴纸要**真正透明的 PNG／WebP**；封面是不透明的。有灰白棋盘格，我会告诉你哪几张要重做（小精灵那次也一样）。
3. 我用 `scripts/teach/art-slice.js` 切开、补洞（贴纸里被围住的半透明处，例如发光的圆环，深色背景上会变黑洞，所以补成奶白底）、缩成 256 像素 WebP（魔王 320、封面 1000 宽），放进 `assets/teach/` 并登记到 `manifest.json`。有图的关卡自动换成你的图，**没图的仍用我画的 SVG**（可以先只画一部分）；还没解锁的关，图会变灰变淡、角上挂一把锁。
4. 日间、夜间、手机、电脑我各截一张图给你核对；风格对不上的退回去重画，不影响其他张。
