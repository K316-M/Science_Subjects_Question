## chap1 第一章：水和氢
- 水煤气与制氢：C(s) + H₂O(g) →［高温］CO(g) + H₂(g)；CO(g) + H₂O(g) →［高温、催化剂］CO₂(g) + H₂(g)；CH₄(g) + H₂O(g) →［高温、催化剂］CO(g) + 3H₂(g)。
- 实验室制氢：活泼金属（Zn、Fe、Mg、Al）与稀盐酸或稀硫酸；Al 也能与 NaOH 溶液反应放出 H₂（2Al + 2NaOH + 2H₂O → 2NaAlO₂ + 3H₂）；金属氢化物与水反应也能放出 H₂（CaH₂ + 2H₂O → Ca(OH)₂ + 2H₂）。
- 易错：铜不能从水蒸气或稀酸中置换出氢气；铁与稀酸反应生成 Fe²⁺（不是 Fe³⁺）。
- 电解水：2H₂O →［电解］2H₂ + O₂，阴极得 H₂、阳极得 O₂，体积比 2 : 1；纯水导电性极弱，要加少量稀硫酸或 NaOH 增强导电性、加快电解（加的物质本身不被消耗）。
- 氢气性质：无色无味、难溶于水（排水集气法收集）、密度最小、可燃（点燃前必须验纯，不纯会爆鸣）；H₂ + Cl₂ →［光照］2HCl。
- 氢气的还原性：加热时能还原 CuO、Fe₃O₄ 等较不活泼金属的氧化物，但不能还原 CaO、Na₂O 这类活泼金属的氧化物。
- 氢气还原 CuO 的操作：先通氢气排空气再加热；结束时先停止加热、继续通氢气到冷却，否则灼热的 Cu 会被空气氧化回黑色的 CuO。
- 用途：充填气球与飞艇、冶炼金属、合成氨与盐酸、氢能（燃烧产物只有水）。
- 烃是只由碳、氢两种元素组成的化合物。

## chap2 第二章：原子与分子
- 相对原子质量、式量（相对分子质量）是比值、没有单位；摩尔质量的单位是 g mol⁻¹，数值上等于式量——两者常被混为一谈。
- 原子的实际质量 ≠ 相对原子质量；原子中质子数 = 电子数，所以原子不带电。
- 质量守恒定律（物质不灭定律）：参与反应各物质的质量总和 = 生成物的质量总和；物理变化不拿来验证这个定律。镁在空气中燃烧後称量变少，是因为部分 MgO 以白烟散逸。
- 倍比定律：同两种元素形成两种化合物，与定量某一元素化合的另一元素质量成简单整数比（例：碳质量相同时，CO₂ 与 CO 中氧的质量比 = 2 : 1）。
- 化合物中各元素正负化合价的代数和为零，可由此推化学式（如由质量百分比求 Mg₃N₂）。
- 物质的量计算：n = m / M、N = n × N_A（6.02 × 10²³ mol⁻¹）。易错：分子数与原子数（32 g O₂ 是 1 mol 分子、2 mol 原子；35.5 g Cl₂ 含 1 mol 原子）；离子得失电子数（1 mol S 变 S²⁻ 得 2 mol 电子）。
- 易错：22.4 L mol⁻¹ 只适用于标准状况下的气体，22.4 mL 液态水约 22.4 g（密度 1 g cm⁻³），不是 1 mol。
- 由质量百分比求实验式，再用式量求分子式（如 CH₂ → C₄H₈）；结晶水数目计算（MgSO₄·7H₂O、CaSO₄·2H₂O）。
- 元素质量百分比比较（尿素 CO(NH₂)₂ 含氮 46.67%，硫酸铵 (NH₄)₂SO₄ 含氮 21.21%）。

## chap3 第三章：化学方程式与化学计算
- 反应类型：化合、分解、置换、复分解（中和是复分解的一种）。
- 置换反应看金属活动性顺序：活动性较弱的金属不能置换较强金属的盐（Pb 不能置换 Sn²⁺）。
- 方程式要配平、注明反应条件（加热、点燃、高温、催化剂 MnO₂ 等）；2KClO₃ →［MnO₂、加热］2KCl + 3O₂。
- 离子方程式：难溶物（CaCO₃、BaSO₄、Mg(OH)₂）、气体、水保留化学式；H₂SO₄ 与 Ba(OH)₂ 反应 H⁺、OH⁻、Ba²⁺、SO₄²⁻ 全部参与，不能只写 H⁺ + OH⁻ → H₂O；Fe 与稀酸生成 Fe²⁺；离子方程式也要电荷守恒、原子守恒。
- 化学计算：按方程式的物质的量之比计算；含杂质（纯度 %）、产率 = 实际产量 ÷ 理论产量 × 100%。
- 限量试剂：两种反应物都给量时，先判断哪一种先用完（例：0.5 mol Cu 与 0.5 mol AgNO₃，AgNO₃ 是限量试剂，析出 0.5 mol Ag）。
- 漂白粉制备：2Cl₂ + 2Ca(OH)₂ → Ca(ClO)₂ + CaCl₂ + 2H₂O（离子式：Cl₂ + 2OH⁻ → ClO⁻ + Cl⁻ + H₂O）。

## chap4 第四章：原子结构
- 质量数 = 质子数 + 中子数；原子序数 = 质子数 = 核电荷数 = 原子的电子数；离子的电子数要加减电荷（H₃O⁺、OH⁻、NH₄⁺ 都是 10 个电子，CH₃⁺ 只有 8 个）。
- 同位素：质子数相同、中子数不同；电子数相同所以化学性质几乎相同，质量（物理性质）不同。同素异形体：同一种元素形成的不同单质。两者常被混淆。
- 由同位素丰度求元素的相对原子质量（例：¹²C 98.9%、¹³C 1.1% → 12.011），或反过来求丰度。
- 电子排布式按能级 1s 2s 2p 3s 3p 4s 3d 填；特例 Cr 是 3d⁵4s¹、Cu 是 3d¹⁰4s¹（半满、全满较稳定）。
- 同一能级的不同轨域能量相同（3p_x = 3p_y = 3p_z）；能写出未成对电子数（N 3 个、Cr 6 个、Mg 0 个）。
- 离子的电子排布：S 1s²2s²2p⁶3s²3p⁴，S²⁻ 1s²2s²2p⁶3s²3p⁶。
- 重水：D₂¹⁶O 与 H₂¹⁸O 的式量都是 20。

## chap5 第五章：元素周期表
- 发展史：德贝莱纳「三元素组」、纽兰兹「八音律」、迈耳「六元素表」、门捷列夫按相对原子质量排列；现代周期律是按核电荷数（原子序数）递增，门捷列夫没认识到周期性变化的根本原因。
- 结构：周期 = 电子层数；短周期（1–3）、长周期、不完全周期；主族、副族（过渡元素）、内过渡元素（镧系、锕系）、稀有气体。
- 由价电子构型定位：IA ns¹、IIA ns²、IIIA ns²np¹、VIIA ns²np⁵、稀有气体 ns²np⁶（He 是 1s²）；能由离子与稀有气体电子层结构相同反推元素（二价阳离子与 Xe 相同 → Ba）。
- 原子半径：同周期从左到右减小（核电荷增加、电子加在同一层）；同主族从上到下增大。阳离子半径小于原子、阴离子半径大于原子。
- 第一电离能：同周期从左到右大体增大、同主族从上到下减小；例外：Mg > Al、P > S（全满 3s²、半满 3p³ 较稳定）。第二电离能 > 第一电离能。
- 逐级电离能出现大突变的位置可推价数：K 在 I₁、I₂ 之间突变 → +1 价；Ca 在 I₂、I₃ 之间突变 → +2 价。
- 电负性：同周期从左到右增大、同主族从上到下减小；电离能越小金属性越强，电负性越大非金属性越强。
- 准金属：B、Si、Ge、As、Sb、Te（金属与非金属分界线附近）。

## chap6 第六章：化学键与分子间作用力
- 化学键三种：离子键、共价键、金属键；分子间作用力（范德华力、氢键）比化学键弱得多。键能比约 共价键 : 氢键 : 范德华力 = 100 : 10 : 1。
- 离子键：活泼金属（K、Na、Ca、Mg）与活泼非金属（F、Cl、Br、O）之间；会写离子化合物的电子式（Na⁺[:Cl:]⁻、Mg²⁺[:O:]²⁻，K₂S 的两个 K⁺ 分开写）。
- 共价键：原子间共用电子对；氢气是共价分子但不是共价化合物（单质不算化合物）。NaOH 是离子化合物，但同时含离子键与共价键（O–H）。
- 键能、键长、键角：破坏化学键吸热、形成化学键放热；单键、双键、三键共用电子对越多，键长越短、键能越大；双原子分子没有键角。
- 配位键：一方单独提供孤对电子、另一方有空轨域（NH₄⁺、H₃O⁺），属于特殊的共价键。
- 极性：电负性差 = 0 非极性键、0～1.7 极性键、≥ 1.7 离子键。由极性键构成的分子不一定是极性分子：CO₂、BF₃、CCl₄、CH₄ 是非极性分子；H₂O、H₂S、NH₃、HCl、CH₃Cl 是极性分子。双原子单质分子都非极性。
- 价层电子对互斥理论：2 对直线形、3 对平面三角形、4 对四面体；有孤对电子时 NH₃ 三角锥形、H₂O 角形。
- 氢键：H 与 F、O、N 相连时形成；使 NH₃、H₂O、HF 的沸点反常地高（NH₃ 易液化、极易溶于水；冰的熔点比一般分子晶体高）。沸点 HF > HI > HBr > HCl；稳定性 HF > HCl > HBr > HI（看键能，不是看氢键）。
- 范德华力随式量（电子数）增大而增强：F₂、Cl₂、Br₂、I₂ 熔沸点逐渐升高。
- 四种晶体：离子晶体（熔沸点高，固态不导电、熔融或溶于水导电）、原子晶体（金刚石、SiC、SiO₂、晶体硅、BN：熔点高、硬度大、不导电、没有独立小分子）、分子晶体（熔沸点低、硬度小；AlCl₃、冰、干冰、碘、固态稀有气体）、金属晶体。
- 易错：AlCl₃ 是共价化合物、分子晶体；固态稀有气体是分子晶体，但分子内没有共价键。
- 金属键强弱看原子半径与单位体积内的自由电子数：Al > Mg > Na；同主族往下金属键减弱、熔点降低。

## chap7 第七章：氧化还原反应
- 氧化数规则：单质为 0；IA 族金属 +1、IIA 族 +2；F 永远 −1；H 一般 +1，在活泼金属氢化物（NaH）中 −1；O 一般 −2，在 OF₂ 中 +2、过氧化物中 −1、超氧化物中 −½；化合物中氧化数代数和为 0，离子中等于电荷。
- 主族元素最高氧化数 = 族序数（F、O、稀有气体除外），最低氧化数 = 族序数 − 8；金属没有负氧化数。
- 本质是电子转移：失电子 → 氧化数升高 → 被氧化 → 作还原剂（有还原性）；得电子 → 氧化数降低 → 被还原 → 作氧化剂。
- 易错：说「氧化剂是 HCl」还是「H⁺ 被还原」要分清物质与粒子；同一种物质在不同反应中可当氧化剂也可当还原剂（H₂ 与 CuO 是还原剂，与 Na 生成 NaH 时是氧化剂；水与 Na 是氧化剂，与 F₂ 是还原剂）。
- 自身氧化还原（歧化）：2H₂O₂ → 2H₂O + O₂、Cl₂ + 2NaOH、3S + 6KOH → 2K₂S + K₂SO₃ + 3H₂O。中间氧化数的物质（Fe²⁺、SO₂、H₂O₂）既有氧化性也有还原性；最高氧化态（C⁴⁺、S⁶⁺）只能被还原。
- 置换反应一定是氧化还原反应；复分解反应一定不是；化合、分解反应可能是也可能不是（CaO + H₂O 不是）。
- 常见氧化剂：卤素、O₂、FeCl₃、浓 H₂SO₄（→SO₂）、HNO₃（稀→NO、浓→NO₂）、KMnO₄（酸性→Mn²⁺）、K₂Cr₂O₇（→Cr³⁺）、过氧化物。常见还原剂：活泼金属、FeCl₂、H₂、C、CO、SO₂、H₂S、HI、Na₂S₂O₃。
- 强弱顺序：氧化性 F₂ > Cl₂ > Br₂ > I₂；还原性 Cs > Rb > K > Na > Li、Ca > Zn > Fe > Cu > Hg；由反应判断：氧化剂的氧化性 > 氧化产物（Cl₂ + 2NaBr → 氧化性 Cl₂ > Br₂、还原性 Br⁻ > Cl⁻）。浓硝酸氧化性强于浓硫酸（与铜反应不需加热）。
- 氧化数法配平：找出升降的元素 → 写半反应 → 使得失电子相等 → 观察法配其余；酸性溶液中缺 O 加 H₂O、缺 H 加 H⁺。常考：2KMnO₄ + 16HCl → 2KCl + 2MnCl₂ + 5Cl₂ + 8H₂O；MnO₄⁻ + 5Fe²⁺ + 8H⁺ → Mn²⁺ + 5Fe³⁺ + 4H₂O；IO₃⁻ + 5I⁻ + 6H⁺ → 3I₂ + 3H₂O；3Cu + 8HNO₃(稀) → 3Cu(NO₃)₂ + 2NO + 4H₂O；Cu + 4HNO₃(浓) → Cu(NO₃)₂ + 2NO₂ + 2H₂O；K₂Cr₂O₇ + 14HCl → 2CrCl₃ + 2KCl + 3Cl₂ + 7H₂O。

## chap8 第八章：钠和钾
- 碱金属在自然界只以化合物存在；价电子 1 个，强还原剂；Li → Cs 金属性、还原性、原子半径递增（K > Na）。
- 物理性质：银白色、质软可用小刀切、熔点低、密度小于水大于煤油，所以保存在煤油中（隔绝空气和水）。
- 与氧气：常温生成 Na₂O、K₂O（切口变暗）；加热燃烧生成过氧化物 Na₂O₂（淡黄色）、K₂O₂；钾在纯氧中燃烧生成超氧化钾 KO₂。易错：钠在空气中燃烧的产物是 Na₂O₂，不是 Na₂O。
- 与水：浮、游、熔成小球、嘶嘶声、酚酞变红、气体可燃（2Na + 2H₂O → 2NaOH + H₂）；钾比钠更剧烈（在冰上也能着火）。与酸反应更剧烈。
- 钠露置空气中的变化：Na → Na₂O → NaOH → Na₂CO₃。
- 制取：电解熔融 NaCl 得 Na（电解 NaCl 水溶液得不到钠，得到 NaOH、H₂、Cl₂——氯碱工业）；KCl(l) + Na(l) →［高温］NaCl(l) + K(g)，钾沸点低、不断蒸出使反应持续。
- 焰色试验：Na 黄色、K 淡紫色（透过蓝色钴玻璃观察）；用洁净的铂丝；玻璃含钠，不能用玻璃棒蘸取。
- NaOH（烧碱、火碱、苛性钠）：溶解放热、易潮解、吸收 CO₂ 变质（检验变质：加盐酸冒气泡、加石灰水或 BaCl₂ 出现沉淀）；能与 Al、SiO₂ 反应（玻璃瓶不能用玻璃塞）。
- Na₂CO₃（苏打、纯碱）与 NaHCO₃（小苏打）：碳酸钠溶解度较大、受热不分解；碳酸氢钠受热分解（2NaHCO₃ → Na₂CO₃ + H₂O + CO₂），与盐酸反应较剧烈（只需 1 个 H⁺）；两者溶液都呈碱性。除去 Na₂CO₃ 中的 NaHCO₃ 用加热。
- KNO₃ 受热分解 2KNO₃ → 2KNO₂ + O₂，有强氧化性（火药）；KCl 作钾肥；NaCl 的用途与过量摄取的危害。

## chap9 第九章：镁和钙
- 碱土金属：价电子 2 个、自然界无单质；Be → Ba 金属性递增；与同周期碱金属相比原子半径小、密度大、硬度大、熔沸点高（金属键强）。
- 镁：常温生成致密氧化膜（不必密封保存）；燃烧发耀眼白光（照明弹），2Mg + O₂ → 2MgO，也与 N₂ 生成 Mg₃N₂；能在 CO₂ 中燃烧 2Mg + CO₂ → 2MgO + C（所以镁着火不能用 CO₂ 灭火）。与冷水反应慢、与沸水较快生成 Mg(OH)₂ + H₂。
- 钙：氧化物疏松不起保护作用、保存在煤油中；与冷水即剧烈反应 Ca + 2H₂O → Ca(OH)₂ + H₂；燃烧生成 CaO 和少量 Ca₃N₂；Ca + H₂ →［高温］CaH₂，CaH₂ + 2H₂O → Ca(OH)₂ + 2H₂。
- 工业上电解熔融氯化物制碱土金属。
- MgO（苦土）：高熔点、耐火材料、碱性氧化物；煅烧菱镁矿 MgCO₃ 制得。MgSO₄·7H₂O 俗称泻盐；MgCl₂·6H₂O 易潮解。
- CaO（生石灰）：与水放大量热生成 Ca(OH)₂；煅烧石灰石制得。Ca(OH)₂（熟石灰、消石灰），水溶液叫石灰水、悬浊液叫石灰乳；用途：漂白粉、建筑、改良酸性土壤。
- 石膏 CaSO₄·2H₂O 加热成熟石膏 2CaSO₄·H₂O，再加水又变回石膏（体积略膨胀）：用于模型、石膏绷带、调节水泥硬化、豆腐凝固剂。
- 无水 CaCl₂：干燥剂、融冰剂；易错：不能用来干燥氨气（生成 CaCl₂·8NH₃）。
- 离子检验：Mg²⁺ 加 NaOH 或氨水生成白色 Mg(OH)₂，不溶于过量（与 Al(OH)₃ 区别）；Ca²⁺ 加草酸根生成 CaC₂O₄，不溶于醋酸、溶于稀盐酸；钙的焰色砖红色；CaSO₄ 微溶，Ba²⁺、Sr²⁺ 才会和硫酸根产生明显白色沉淀。

## chap10 第十章：铝
- 地壳中含量最多的金属（地壳四大元素：O、Si、Al、Fe）；第 3 周期 IIIA 族，[Ne]3s²3p¹。
- 物理性质与用途要对应：导线（导电）、铝锅（导热）、铝箔（延展性）、银色油漆（金属光泽）、门窗与车架（合金强度高、抗腐蚀）。
- 常温形成致密氧化膜所以耐腐蚀（铁锈疏松不保护）；冷的浓硫酸、浓硝酸使铝钝化，铝容器可盛装冷浓硫酸、冷浓硝酸（铜不会钝化）。
- 两性：2Al + 6HCl → 2AlCl₃ + 3H₂；2Al + 2NaOH + 2H₂O → 2NaAlO₂ + 3H₂（其他常见金属不与强碱反应）。氧化膜溶解後才开始冒气泡。
- 铝热反应：2Al + Fe₂O₃ →［高温］2Fe + Al₂O₃，放出大量热，用来焊接钢轨、冶炼难熔金属（Cr 等）；用镁条引燃、KClO₃ 助燃。
- Al₂O₃：高熔点、硬度大、两性氧化物（与 H₂SO₄、NaOH 都反应）。
- Al(OH)₃：白色胶状、两性氢氧化物（溶于酸与强碱，不溶于氨水）；实验室用铝盐 + 氨水制取（用 NaOH 会过量溶解）；胃酸中和剂；受热分解吸热可作阻燃剂。
- 鉴别：向 Al³⁺ 滴加 NaOH 先产生白色沉淀、过量後沉淀溶解；Mg²⁺ 的沉淀不溶。
- 明矾 KAl(SO₄)₂·12H₂O 是复盐，Al³⁺ 水解生成 Al(OH)₃ 吸附悬浮物，用作净水剂。
- 冶炼：电解熔融 Al₂O₃，加冰晶石 Na₃AlF₆ 作助熔剂降低熔点：2Al₂O₃ →［电解］4Al + 3O₂。

## chap11 第十一章：碳和硅
- IVA 族从上到下原子半径增大、失电子能力增强，金属性递增、非金属性递减（C、Si 非金属，Ge 准金属，Sn、Pb 金属）。
- 碳的同素异形体：金刚石、石墨（原子排列不同，是不同物质）；无定形碳：焦炭、活性炭（表面积大、吸附异味、色素）。常温下碳的化学性质稳定。
- CO：可燃（蓝色火焰）、有毒、有还原性；水煤气 C + H₂O →［高温］CO + H₂。
- CO₂：CO₂ + H₂O ⇌ H₂CO₃（使紫色石蕊变红，加热又变回紫色）；通入石灰水先变浑浊（CaCO₃）、过量後又变澄清（生成可溶的 Ca(HCO₃)₂）。实验室制法 CaCO₃ + 2HCl → CaCl₂ + H₂O + CO₂。
- 硬水与水垢：Ca(HCO₃)₂、Mg(HCO₃)₂ 受热分解生成难溶的 CaCO₃、MgCO₃。
- 硅：良好的半导体；工业制粗硅 SiO₂ + 2C →［高温］Si + 2CO。SiO₂：光导纤维；原子晶体，熔沸点高、常温固态；CO₂ 是分子晶体、常温气态——两者常一起比较。
- 盛 NaOH 溶液的试剂瓶用橡皮塞，不用玻璃塞（SiO₂ + 2NaOH → Na₂SiO₃ + H₂O，硅酸钠有黏性）。水玻璃（Na₂SiO₃ 溶液）在空气中与 CO₂ 反应生成硅酸沉淀。
- 证明 C 的非金属性比 Si 强：电负性 C 2.5 > Si 1.8；氢化物 CH₄ 比 SiH₄ 稳定；最高价含氧酸 H₂CO₃ 酸性比 H₂SiO₃ 强（强酸制弱酸）。
- 硅酸盐材料：水泥、陶瓷、玻璃。

## chap12 第十二章：氮和磷
- VA 族：N、P、As、Sb、Bi（、Mc），5 个价电子，从上到下原子半径增大、非金属性减弱；氮的氧化数 −3 到 +5 都有。
- N₂：N≡N 结构稳定、常温不活泼；N₂ + 3H₂ ⇌［催化剂、高温、高压］2NH₃（哈伯法）；N₂ + O₂ →［放电或高温］2NO；3Mg + N₂ →［点燃］Mg₃N₂；Li 与 Mg 相似（6Li + N₂ → 2Li₃N）。用途：合成氨、保护气（焊接、灯泡、食品）、液氮冷冻剂。工业上分馏液态空气制取。
- 氮的氧化物：N₂O（笑气、麻醉剂，NH₄NO₃ 受热分解制得）、NO（无色、难溶于水、只能用排水法收集，遇空气立刻变成红棕色 NO₂）、NO₂（红棕色、易溶于水，3NO₂ + H₂O → 2HNO₃ + NO，NO₂ 既是氧化剂也是还原剂；2NO₂ ⇌ N₂O₄ 低温变无色）。光化学烟雾、酸雨。
- 硝酸：无色易挥发；见光分解 4HNO₃ → 4NO₂ + O₂ + 2H₂O，所以浓硝酸常呈黄色、要用棕色瓶。一元强酸但与金属反应不放出 H₂；稀硝酸 → NO、浓硝酸 → NO₂；一般硝酸越稀、金属越活泼，氮被还原得越低。冷浓硝酸使铁、铝钝化；王水（浓硝酸 : 浓盐酸 = 1 : 3）能溶解金、铂。浓硝酸与碳：C + 4HNO₃ → CO₂ + 4NO₂ + 2H₂O。
- 硝酸的制法：实验室 NaNO₃ + H₂SO₄(浓) → NaHSO₄ + HNO₃；工业氨催化氧化 4NH₃ + 5O₂ → 4NO + 6H₂O，再 2NO + O₂ → 2NO₂、3NO₂ + H₂O → 2HNO₃ + NO。
- 硝酸盐受热分解：活泼金属（K、Na）→ 亚硝酸盐 + O₂；Mg 到 Cu → 金属氧化物 + NO₂ + O₂（2Cu(NO₃)₂ → 2CuO + 4NO₂ + O₂）；Hg、Ag → 金属 + NO₂ + O₂（2AgNO₃ → 2Ag + 2NO₂ + O₂，NO₂ : O₂ = 2 : 1）。黑火药 2KNO₃ + 3C + S → K₂S + N₂ + 3CO₂。
- 硝酸根检验：棕色环实验（新制 FeSO₄ 溶液，沿管壁加浓硫酸，界面出现棕色环 FeSO₄·NO）。
- NH₃：无色有刺激性气味、比空气轻、极易溶于水（喷泉实验）、易液化（分子间氢键，液氨作制冷剂）；氨水 NH₃·H₂O 部分电离显弱碱性；遇 HCl 生成白烟 NH₄Cl；有还原性（4NH₃ + 5O₂ → 4NO + 6H₂O；3CuO + 2NH₃ → 3Cu + N₂ + 3H₂O）。
- 实验室制氨：2NH₄Cl + Ca(OH)₂ →［加热］CaCl₂ + 2NH₃ + 2H₂O；用湿润的红色石蕊试纸检验（变蓝）；不能用排水法收集；不能用浓硫酸或无水 CaCl₂ 干燥（用碱石灰）。
- 铵盐：受热分解一般放出 NH₃（NH₄Cl → NH₃ + HCl，遇冷又化合，是化学变化，与碘升华的物理变化不同）；NH₄NO₃ 分解生成 N₂O（是氧化还原反应）；铵盐 + 碱 → NH₃（检验 NH₄⁺；铵态氮肥不能与碱性肥料混用）。
- 磷：白磷（剧毒、着火点约 40°C、保存在水中、暗处发光、溶于 CS₂）与红磷（无毒、240°C 才着火、可放空气中）是同素异形体。4P + 5O₂ → 2P₂O₅（白烟）；氧气或氯气不足时生成 +3 价化合物。
- P₂O₅ 与冷水生成偏磷酸 HPO₃（有毒）、与热水生成磷酸 H₃PO₄；磷酸是三元酸，有正盐、磷酸氢盐、磷酸二氢盐；磷酸二氢盐都易溶，其他除 K、Na、铵盐外几乎都不溶。

## chap13 第十三章：氧和硫
- VIA 族：O、S、Se、Te、Po，ns²np⁴；从上到下电负性、非金属性递减，熔沸点、密度递增。硫常见氧化数 −2、0、+4、+6。
- 氧气：无色无味、略溶于水（排水法收集）、液态与固态呈蓝色。铁丝在空气中只红热、在纯氧中剧烈燃烧火星四射生成黑色 Fe₃O₄；硫在空气中淡蓝色火焰、在纯氧中蓝紫色火焰。
- 实验室制 O₂：加热 KMnO₄（2KMnO₄ → K₂MnO₄ + MnO₂ + O₂）、KClO₃ 加 MnO₂ 共热、H₂O₂ 加 MnO₂（不需加热最简单）、2Na₂O₂ + 2H₂O → 4NaOH + O₂；MnO₂ 是催化剂。工业：分馏液态空气。
- 臭氧 O₃：与 O₂ 是同素异形体；淡蓝色、有刺激性臭味、比 O₂ 易溶于水；不稳定（2O₃ → 3O₂）、强氧化性（PbS + 2O₃ → PbSO₄ + O₂，使湿润的 KI 淀粉试纸变蓝）；闪电或高压放电时生成；吸收紫外线；用于饮用水消毒（不会产生有毒的有机氯化物）。NO 会催化破坏臭氧层。
- 氧化物分类：普通氧化物（O 为 −2）、过氧化物（−1：H₂O₂、Na₂O₂、BaO₂）、超氧化物（−½：KO₂）、复合氧化物 Fe₃O₄（FeO·Fe₂O₃）；碱性、酸性、两性（ZnO、Al₂O₃、SnO₂、PbO）、中性（CO、NO、N₂O、H₂O）。
- H₂O₂：分子间氢键使沸点比水高；水溶液弱酸性；见光、遇碱或 MnO₂ 易分解（棕色瓶、阴凉处）；既有氧化性（被还原为水，PbS → PbSO₄，Fe²⁺ → Fe³⁺）也有还原性（被 KMnO₄、K₂Cr₂O₇ 氧化成 O₂，使酸性 KMnO₄ 褪色）。
- Na₂O₂（浅黄色）：2Na₂O₂ + 2H₂O → 4NaOH + O₂、2Na₂O₂ + 2CO₂ → 2Na₂CO₃ + O₂（密闭环境的供氧剂；着火不能用水或 CO₂ 灭）。KO₂：4KO₂ + 2H₂O → 4KOH + 3O₂，用于防毒面罩。
- 硫：淡黄色、不溶于水、易溶于 CS₂；同素异形体菱形硫、单斜硫、弹性硫（S₈ 环）。作氧化剂：Fe + S → FeS（只到 +2）、2Ag + S → Ag₂S（银器变黑）、Hg + S → HgS（处理洒落的汞）；作还原剂：S + O₂ → SO₂、S + 2H₂SO₄(浓) → 3SO₂ + 2H₂O；歧化 3S + 6NaOH → 2Na₂S + Na₂SO₃ + 3H₂O。
- H₂S：无色、臭蛋味、剧毒、比空气略重；水溶液（氢硫酸）是二元弱酸；强还原性（被 Cl₂、FeCl₃、SO₂、浓 H₂SO₄、KMnO₄、HNO₃ 氧化为 S，溶液变浑浊；2H₂S + SO₂ → 3S + 2H₂O）；完全燃烧生成 SO₂、不完全燃烧生成 S。实验室 FeS + 2HCl → FeCl₂ + H₂S（启普发生器、向上排空气法）；用醋酸铅试纸检验（变黑 PbS）。
- SO₂：无色有刺激性气味、有毒、易液化、易溶于水；酸性氧化物（亚硫酸酐，H₂SO₃ 不稳定、易被氧化成 H₂SO₄，酸雨的 pH 会变小）；以还原性为主（使 KMnO₄ 褪色、橙色 K₂Cr₂O₇ 变墨绿色；2SO₂ + O₂ ⇌［V₂O₅、400–500°C］2SO₃）、也有氧化性（与 H₂S 生成 S）。
- 漂白比较：SO₂ 与色素化合成不稳定的无色物，品红褪色後加热恢复（非永久）；H₂O₂、O₃、Na₂O₂、ClO⁻ 靠氧化性永久漂白；活性炭是物理吸附。
- 易错：CO₂ 或 SO₂ 通入 BaCl₂ 溶液不产生沉淀（弱酸不能制强酸）；通入石灰水都会变浑浊（CaCO₃、CaSO₃），所以不能只用石灰水区别 CO₂ 与 SO₂（用品红或 KMnO₄）。
- 浓硫酸：吸水性（干燥剂，但不能干燥 NH₃、H₂S、HBr、HI 等碱性或还原性气体）、脱水性（使蔗糖炭化变黑、胆矾变白）、强氧化性（加热时与 Cu、C、S 反应生成 SO₂，与 Fe 生成 Fe³⁺；常温使 Fe、Al 钝化）。稀硫酸与 Cu 不反应、与 Fe 生成 FeSO₄ + H₂。稀释浓硫酸要把酸慢慢倒入水中。
- 接触法制硫酸：燃烧 S 或 FeS₂（4FeS₂ + 11O₂ → 2Fe₂O₃ + 8SO₂）→ 净化（防催化剂 V₂O₅ 中毒）→ 2SO₂ + O₂ ⇌ 2SO₃ → 用浓硫酸吸收 SO₃（用水会形成酸雾）得发烟硫酸，再稀释。
- 硫酸根检验：先加盐酸酸化（排除 CO₃²⁻、SO₃²⁻、Ag⁺），再加 BaCl₂ 出现白色沉淀；不能用硝酸酸化或用 Ba(NO₃)₂（会把 SO₃²⁻ 氧化成 SO₄²⁻）。
- 硫酸盐：一般易溶；CaSO₄、Ag₂SO₄ 微溶，BaSO₄、PbSO₄ 难溶；BaSO₄ 作钡餐（X 光造影剂）；绿矾 FeSO₄·7H₂O、皓矾 ZnSO₄·7H₂O、胆矾 CuSO₄·5H₂O、明矾 KAl(SO₄)₂·12H₂O。

## chap14 第十四章：卤素
- VIIA 族 F、Cl、Br、I、At，7 个价电子，易得 1 个电子、常见氧化数 −1；从上到下原子半径增大，电负性、氧化性、非金属性递减；单质熔沸点升高（式量增大、范德华力增强）。
- 单质颜色状态：F₂ 淡黄色气体、Cl₂ 黄绿色气体、Br₂ 深红棕色液体、I₂ 紫黑色固体（易升华）；都有毒。
- 与金属：Na 在 Cl₂ 中燃烧生白烟；Fe 在 Cl₂ 中燃烧生成 FeCl₃（棕褐色烟，不是 FeCl₂）；Cu 生成 CuCl₂（棕黄色烟，溶于水呈蓝绿色）。燃烧不一定需要氧气，本质是氧化还原。
- 与 H₂ 的难易反映氧化性：F₂ 冷暗处即爆炸、Cl₂ 光照或点燃、Br₂ 要加热、I₂ 要高温且可逆；氢化物稳定性 HF > HCl > HBr > HI；卤离子还原性 I⁻ > Br⁻ > Cl⁻ > F⁻。
- 与水：2F₂ + 2H₂O → 4HF + O₂（F₂ 氧化水）；Cl₂ + H₂O ⇌ HCl + HClO，Br₂、I₂ 越来越弱。干燥 Cl₂ 没有漂白性，起漂白作用的是 HClO；氯水使 pH 试纸先变红後褪色；HClO 见光分解 2HClO → 2HCl + O₂，所以氯水要新制、用棕色瓶。
- 与碱：Cl₂ + 2NaOH(冷稀) → NaCl + NaClO + H₂O；3Cl₂ + 6NaOH(热浓) → 5NaCl + NaClO₃ + 3H₂O。漂白粉 2Cl₂ + 2Ca(OH)₂ → CaCl₂ + Ca(ClO)₂ + 2H₂O，有效成分 Ca(ClO)₂；Ca(ClO)₂ + CO₂ + H₂O → CaCO₃ + 2HClO，要密封防潮。
- 置换：Cl₂ 能置换 Br⁻、I⁻；加 CCl₄ 萃取分层，下层 Br₂ 橙红色、I₂ 紫红色；Cl₂ 使湿润的淀粉 KI 试纸变蓝。
- 实验室制 Cl₂：MnO₂ + 4HCl(浓) →［加热］MnCl₂ + Cl₂ + 2H₂O（稀盐酸不行）；2KMnO₄ + 16HCl(浓) → 2KCl + 2MnCl₂ + 5Cl₂ + 8H₂O（不需加热）。
- 氯碱工业：电解饱和食盐水 2NaCl + 2H₂O → 2NaOH + H₂ + Cl₂；阳极（接正极）得 Cl₂、阴极（接负极）得 H₂ 与 NaOH；阳离子交换膜防止 H₂ 与 Cl₂ 混合爆炸、防止 Cl₂ 与 OH⁻ 反应。
- HCl：无色刺激性、极易溶于水（喷泉实验）；干燥 HCl 不显酸性；浓盐酸易挥发、在空气中形成白雾；遇 NH₃ 产生白烟。实验室 NaCl + H₂SO₄(浓) → NaHSO₄ + HCl（溶于水时用倒置漏斗防倒吸）；不能用浓硫酸制 HBr、HI（Br⁻、I⁻ 会被氧化）。
- 卤离子检验：加 AgNO₃ 与稀硝酸：AgCl 白色、AgBr 淡黄色、AgI 黄色，都不溶于稀硝酸（Ag₂CO₃ 溶于稀硝酸，所以要加稀硝酸排除 CO₃²⁻）；卤化银见光分解（感光材料）。难溶卤化物：AgCl、AgBr、AgI、PbCl₂、PbBr₂、PbI₂。
- 卤素含氧酸：氟没有含氧酸；HClO、HClO₂、HClO₃、HClO₄ 氧化数 +1、+3、+5、+7，稳定性与酸性依次增强、氧化性依次减弱（HClO 氧化性最强、HClO₄ 酸性最强）。

## chap15 第十五章：过渡元素
- 过渡元素：(n−1)d 或 f 轨域未填满；都是金属、最外层电子不超过 2 个；多种氧化数（第一过渡系除 Sc、Zn 外）、易形成有色化合物（d 电子跃迁吸收可见光）、易形成配位化合物、多具催化性。熔点最高钨、密度最大锇、硬度最大铬。
- 配位化合物：配位体提供孤对电子、中心离子有空轨域。AgNO₃ 加氨水先沉淀、过量溶解成 [Ag(NH₃)₂]⁺；CuSO₄ 加氨水先生成蓝色 Cu(OH)₂、过量溶解成深蓝色 [Cu(NH₃)₄]²⁺。CoCl₂ 蓝色、CoCl₂·6H₂O 粉红色（检验水）。
- 铁：[Ar]3d⁶4s²，常见 +2、+3；Fe³⁺ 比 Fe²⁺ 稳定（3d⁵ 半满）。与弱氧化剂（S、H⁺、Cu²⁺）生成 Fe²⁺，与强氧化剂（Cl₂、O₂ 燃烧、HNO₃）生成 Fe³⁺：Fe + S → FeS、2Fe + 3Cl₂ → 2FeCl₃、3Fe + 2O₂ → Fe₃O₄、3Fe + 4H₂O(g) →［高温］Fe₃O₄ + 4H₂。
- 铁的氧化物：FeO 黑色、Fe₂O₃ 红棕色（铁红）、Fe₃O₄ 黑色有磁性（FeO·Fe₂O₃）；都不溶于水。
- 氢氧化物：Fe(OH)₃ 红褐色沉淀；Fe(OH)₂ 白色沉淀迅速变灰绿色、最後变红褐色（4Fe(OH)₂ + O₂ + 2H₂O → 4Fe(OH)₃）。
- Fe²⁺ ⇌ Fe³⁺：Fe²⁺ 加氧化剂（Cl₂、H₂O₂）变 Fe³⁺；Fe³⁺ 加还原剂（Fe、Cu）变 Fe²⁺（2FeCl₃ + Cu → 2FeCl₂ + CuCl₂，用来腐蚀印刷电路铜板）；保存 Fe²⁺ 溶液要加少量铁粉。
- 检验：Fe³⁺ 遇 KSCN 变血红色（Fe²⁺ 不变色）；加 NaOH 看沉淀颜色；K₄[Fe(CN)₆]（黄色）遇 Fe³⁺、K₃[Fe(CN)₆]（红色）遇 Fe²⁺ 都生成深蓝色沉淀；H₂S 把 Fe³⁺ 还原、生成黄色 S。
- 混合问题：Fe、Cu 与 FeCl₃ 反应後，有 Fe 剩下就一定有 Cu；有 Cu 剩下不一定有 Fe；溶液中有 Cu 时不可能有 Fe³⁺。
- 炼铁（还原）：焦炭生成 CO，Fe₂O₃ + 3CO → 2Fe + 3CO₂；石灰石除去 SiO₂ 造渣（CaO + SiO₂ → CaSiO₃）。炼钢（氧化）：吹 O₂ 除去过多的碳与杂质，再加硅铁、锰铁、铝脱氧。生铁含碳多、硬而脆；钢含碳少、有韧性；合金是混合物、比纯金属硬。
- 铜：[Ar]3d¹⁰4s¹，常见 +1、+2；紫红色、导电性好；合金黄铜（Cu-Zn）、青铜（Cu-Sn）。在潮湿空气生成铜绿 Cu₂(OH)₂CO₃；加热生成黑色 CuO；与硫生成 Cu₂S（S 氧化性弱）、与 Cl₂ 生成 CuCl₂；不与稀盐酸、稀硫酸反应，与浓硫酸（加热）、浓硝酸、稀硝酸反应。
- 铜的化合物：Cu₂O 红色、CuO 黑色；无水 CuSO₄ 白色遇水变蓝（检验水），胆矾 CuSO₄·5H₂O（波尔多液）；Cu²⁺ 检验：NaOH 生成蓝色 Cu(OH)₂、H₂S 生成黑色 CuS（不溶于酸）、氨水先沉淀後溶解成深蓝色。
- 冶炼：黄铜矿 CuFeS₂ 焙烧 → Cu₂S → Cu₂O，2Cu₂O + Cu₂S → 6Cu + SO₂；再电解精炼。

## chap16 第十六章：气体
- 定律名称照课本：波义耳定律（等温 p₁V₁ = p₂V₂）、查理定律（等压 V₁/T₁ = V₂/T₂）、压强定律（等容 p₁/T₁ = p₂/T₂）、合并为 p₁V₁/T₁ = p₂V₂/T₂；盖·吕萨克定律指「气体反应体积定律」（同温同压下参加反应与生成的气体体积成简单整数比，如 2CO + O₂ → 2CO₂ 为 2 : 1 : 2）。
- 温度一律换成热力学温度 T（K）= t（°C）+ 273；体积、压强前後单位一致即可；这些定律只适用于一定质量的气体、压强不太大、温度不太低。
- 液柱题：开口向上 p = p₀ + p液柱、开口向下 p = p₀ − p液柱、水平 p = p₀（cmHg）。
- 格雷姆扩散定律：同温同压下扩散速率 v ∝ 1/√M，v_a/v_b = √(M_b/M_a)，扩散时间 t_a/t_b = √(M_a/M_b)；例：H₂ 的扩散速率是 O₂ 的 4 倍、是 SO₂ 的 4√2 倍；NH₃ 与 HCl 在长管中相遇的位置靠近 HCl 一端（NH₃ 较轻、走得较远）。
- 阿伏加德罗定律：同温同压下，相同体积的任何气体含相同分子数；同温同压下体积比 = 物质的量之比 = 分子数之比；可用来由体积比推化学式（X₂ + 3Y₂ → 2XY₃）。
- 气体摩尔体积：STP（273 K、1.01 × 10⁵ Pa）下 1 mol 任何气体约 22.4 L；只适用于气体（易错：水在 STP 不是气体；不在 STP 不能用 22.4）。气体体积主要取决于分子间距离，固体、液体体积取决于微粒大小。M = ρ × 22.4（STP 下由密度求摩尔质量）。
- 理想气体：分子没有体积、分子间没有作用力（不是没有质量）；高温、低压时真实气体最接近理想气体；真实气体用范德华方程式修正（分子有体积、有分子间作用力）。
- pV = nRT：R = 8.314 J mol⁻¹ K⁻¹；p 用 Pa、V 用 m³（1 L = 10⁻³ m³）、T 用 K；由 pV = (m/M)RT 求 M（相对分子质量没有单位）、由 M = ρRT/p 求式量；钢瓶漏气、剩余质量这类题。
- 道尔顿分压定律：p_总 = p_A + p_B + …，p_A = p_总 × χ_A（摩尔分数）；排水集气法收集的气体要扣掉水的饱和蒸气压：p(气体) = p_总 − p(H₂O)；分体积 V_A = V_总 × p_A / p_总。质量相同的气体，摩尔质量越小分压越大。
- 气体分子运动论的假设：分子当质点、做快速无规则运动、完全弹性碰撞、压强来自分子撞器壁、分子间作用力忽略。
- 相变：汽化吸热（摩尔汽化热为正）、凝结放热，同一物质摩尔凝结热与摩尔汽化热数值相同、符号相反；蒸发在任何温度、只在液面；沸腾在沸点、液体内部与表面同时进行，沸腾时继续加热温度不变；饱和蒸气压随温度升高而增大，饱和蒸气压等于外界压强时的温度就是沸点；临界温度以上加压也不能液化。

## chap17 第十七章：溶液及其性质
- 溶液是均匀、稳定的混合物（透明但可以有颜色）；溶液、溶质、溶剂可以是气、液、固态（空气是气态溶液、合金是固态溶液）；碘酒的溶剂是酒精。
- 溶解过程：离子化合物在水中电离、溶液能导电；共价化合物（蔗糖）只是被水分子隔开、不导电；相似相溶（极性溶质溶于极性溶剂，油污用油溶）。
- 饱和、不饱和、过饱和溶液（过饱和不稳定，投入晶种就结晶）；饱和 ≠ 浓：CaSO₄ 的饱和溶液是稀溶液，低温的饱和溶液可能比高温的不饱和溶液稀。转换方法：加溶剂或升温（对溶解度随温度上升的物质）变不饱和；减少溶剂、加溶质、降温变饱和。
- 溶解度：一定温度下 100 g 溶剂最多能溶解的溶质克数。大多数固体溶解度随温度升高而增大（KNO₃ 变化大、NaCl 变化小——KNO₃ 用冷却结晶、NaCl 用蒸发结晶）；气体溶解度随压强增大而增大、随温度升高而减小（夏天湖里缺氧）。
- 溶解度计算：溶质 : 溶剂 : 溶液 = S : 100 : (100 + S)；降温析出晶体时溶剂质量不变；结晶水算进溶剂（配 CuSO₄ 溶液要用 CuSO₄·5H₂O 换算）。
- 分配定律与萃取：萃取剂与原溶剂互不相溶、溶质在萃取剂中溶解度更大（酒精与水互溶，不能当萃取剂）；K = c_A / c_B；同量萃取剂分多次萃取比一次萃取出更多；CCl₄ 密度比水大，碘的 CCl₄ 层在下层呈紫红色。
- 浓度：质量百分比 ω、体积百分比、物质的量浓度 c_M（mol/L，按溶液体积）、质量摩尔浓度 c_m（mol/kg，按溶剂质量）；换算 c_M = 1000ωρ / M；稀释前後溶质质量（物质的量）不变；1 mol 溶质加 1 L 水 ≠ 1 mol/L（溶液体积 ≠ 溶剂体积）。
- 配制一定物质的量浓度溶液：计算、称量、溶解、转移、洗涤、定容、摇匀；误差分析（溶质少了浓度偏小、定容时溶液体积偏小或趁热定容浓度偏大）。
- 理想溶液：任意比例互溶、混合时无热效应、体积可加和、符合拉乌尔定律；无限稀或成分相似（苯与甲苯）的溶液接近理想溶液。
- 依数性（只与溶质粒子数有关，与溶质种类无关）：拉乌尔定律 p_液 = p_剂 χ_剂、Δp = p_剂 χ_质；两种挥发性液体 p_总 = p_A° χ_A + p_B° χ_B；A–B 作用力小于 A–A、B–B 时正偏差，大于时负偏差。
- 沸点上升 ΔT_b = K_b c_m、凝固点下降 ΔT_f = K_f c_m（K_b、K_f 是溶剂的特征常数）；可由此求相对分子质量；电解质要乘以 1 mol 溶质解离出的离子数（NaCl 2、MgCl₂ 3、Al(NO₃)₃ 4）。生活例：汤的沸点比水高、溶液的凝固点比纯溶剂低。

## chap18 第十八章：化学反应和能量
- 放热反应：燃烧、金属与酸、中和、生石灰加水；吸热反应：Ba(OH)₂·8H₂O 与 NH₄Cl、C 与 H₂O(g)、多数分解反应、电解。无论吸热还是放热，反应开始都要先吸收能量（断键）。
- 断键吸热、成键放热；键能：破坏 1 mol 气态共价键所需能量；ΔH = 反应物总键能 − 生成物总键能（例：H₂ + Cl₂ → 2HCl，436.4 + 242.7 − 2 × 431.8 = −184.5 kJ）。
- 焓变 ΔH = 生成物总焓 − 反应物总焓，单位 kJ/mol；ΔH < 0 放热、> 0 吸热。
- 热化学方程式：必须注明物质状态（H₂O(g) 与 H₂O(l) 的 ΔH 不同：−241.8 与 −285.8 kJ/mol）、可以用分数系数、ΔH 与系数成正比（系数加倍 ΔH 加倍、反应反写 ΔH 变号）；热化学标准状态 25°C、1.01 × 10⁵ Pa。
- 标准生成热 ΔH_f°：由稳定单质生成 1 mol 化合物的反应热；稳定单质（如石墨、O₂(g)）的生成热为 0；生成热越低、物质越稳定。
- 燃烧热 ΔH_c：1 mol 物质完全燃烧（生成最稳定的氧化物，H 生成 H₂O(l)）的反应热，一定是负值；按每克比较，H₂ 放热比 CH₄ 多（−142.9 对 −55.64 kJ/g）；氢能的优点与难题（制取成本、储存）。
- 中和热：强酸与强碱稀溶液生成 1 mol H₂O 约 −57.3 kJ/mol；弱酸或弱碱电离要吸热，中和热数值较小；浓硫酸溶于水放热，测得的数值偏大。易错：按生成的水的物质的量算，H₂SO₄ 与 NaOH 要看哪一个限量。
- 量热计：Q = mcΔT（c 水 = 4.18 kJ kg⁻¹ K⁻¹），用泡沫塑料杯、不用金属容器；散热、混合时的热量损失、没读到最高温度都会使测得的中和热偏低。
- 黑斯定律：反应热只与始态、终态有关，与途径无关；用已知反应式反写、乘系数、相加求未知 ΔH（如由燃烧热求 CO、CH₄、C₂H₂、C₆H₆ 的生成热）。
- 能源：化石燃料不可再生；新能源有太阳能、地热能、风能、海洋能、生物质能；地球上的基本能源是太阳能。

## chap19 第十九章：化学反应速率
- 速率 = 单位时间内反应物浓度的减少或生成物浓度的增加（如 mol L⁻¹ min⁻¹）；同一反应中各物质的速率比 = 方程式系数比，比较快慢要先换成同一种物质。
- 影响因素：反应物本性（主要因素；离子反应极快，有机共价分子反应慢）、固体表面积（粉末比块状快，面粉厂粉尘爆炸）、浓度、气体压强（改变浓度）、温度、催化剂、光。
- 碰撞理论：活化分子发生有效碰撞（能量足够、方向合适）才反应；增加浓度使单位体积内活化分子数增加；纯固体、纯液体不算浓度（加更多固体或纯液体不改变速率）。
- 速率方程式 R = k[A]ᵐ[B]ⁿ，级数 m、n 只能由实验数据推出，不能直接看方程式系数（2NO + 2H₂ 实验得 R = k[NO]²[H₂]，说明不是一步完成）；一步完成的简单反应才能用系数当级数（3A + B → 2C 一步完成为四级）。
- 复杂反应由最慢的一步决定速率（速率决定步骤）；会由表格数据求级数与 k、k 的单位（零级 M min⁻¹、一级 min⁻¹、二级 M⁻¹ min⁻¹、三级 M⁻² min⁻¹）。
- k 随温度、催化剂改变，不受浓度影响。
- 温度：升温使高能分子增加、有效碰撞增加；经验规则：温度每升高 10°C，速率约变为 2 倍，R₂ = R₁ × 2^(ΔT/10)（例：升高 25°C 约 5.66 倍；降低 20°C 变 1/4）。
- 活化能 Ea：Ea 越大速率越慢；Ea 不随温度改变；能量图上 ΔH = Ea(正) − Ea(逆)。
- 催化剂：改变反应途径、降低 Ea，正逆反应同等程度加快；不改变反应热，也不改变平衡时生成物的量；有选择性；不能使不能发生的反应发生。会在反应机理中区分催化剂（先消耗、後再生）与中间产物（先生成、後消耗）。
- 图像题：镁与盐酸开始时放热使温度升高、速率加快，後来浓度下降、速率减小。

## chap20 第二十章：化学平衡的移动
- 可逆反应达到平衡时 R正 = R逆 ≠ 0（动态平衡，反应没有停止）；各物质浓度不再改变（但不一定相等）；平衡可以从正、逆两个方向达到。特征口诀：逆、等、动、定、变。
- 平衡常数 K_c = [生成物]^系数 的乘积 ÷ [反应物]^系数 的乘积；纯固体、纯液体不写进表达式；K_c 只随温度改变，与起始浓度无关，使用时要注明温度；K_c 越大反应进行得越完全。
- K 与方程式写法：反应反写 K 变成倒数；系数减半 K 开平方（H₂ + I₂ ⇌ 2HI 的 K = 49，½H₂ + ½I₂ ⇌ HI 的 K = 7，2HI ⇌ H₂ + I₂ 的 K = 1/49）。
- 计算用「开始、转化、平衡」三行式（单位 mol/L，体积不是 1 L 要先换算浓度）；转化率 = 已转化 ÷ 起始 × 100%；解二次方程要舍去不合理的根（浓度不能为负、转化量不能超过起始量）。
- 浓度：增加反应物或减少生成物 → 平衡向正反应方向移动；新平衡中被加入的物质浓度仍比原来大（只能削弱、不能抵消）。
- 压强：只影响有气体、且反应前後气体分子总数不等的反应；增大压强向气体分子数（体积）减少的方向移动；H₂ + I₂ ⇌ 2HI、CO + H₂O ⇌ CO₂ + H₂ 不受压强影响。
- 温度：升温向吸热方向移动、降温向放热方向移动；温度是唯一会改变 K 值的因素（放热反应升温 K 变小）。
- 催化剂：同等加快正逆反应，缩短达到平衡的时间，不使平衡移动、不改变产率。
- 勒沙特列原理：改变影响平衡的一个条件，平衡向减弱这种改变的方向移动。
- 合成氨 N₂ + 3H₂ ⇌ 2NH₃（ΔH = −92.4 kJ）：高压有利；低温有利于产率但速率太慢，折衷取约 500°C 并用催化剂；不断分离出 NH₃、补充 N₂ 与 H₂。

## chap21 第二十一章：水溶液中的离子平衡
- 电解质：在水溶液中或熔融状态下能导电的化合物（NaCl、冰醋酸、BaSO₄、NH₄Cl）；非电解质：两种情况下都不导电的化合物（酒精、葡萄糖、蔗糖）；单质与混合物（铜、石墨、NaOH 溶液、碘酒）两者都不是。易错：BaSO₄ 难溶但是电解质。
- 溶解平衡：饱和溶液中溶解速率 = 结晶速率的动态平衡（饱和 CuSO₄ 溶液中晶体形状改变、质量不变）；难溶电解质（溶解度 < 0.01 g/100 g 水）仍会少量溶解。
- 溶度积 K_sp：AₘBₙ(s) ⇌ mAⁿ⁺ + nBᵐ⁻，K_sp = [Aⁿ⁺]ᵐ[Bᵐ⁻]ⁿ，只与本性和温度有关；会写 CaCO₃、Mg(OH)₂、Al(OH)₃、Ca₃(PO₄)₂ 的表达式。
- K_sp 与溶解度 s（mol/L）换算：AB 型 K_sp = s²、AB₂ 型 4s³、AB₃ 型 27s⁴、A₃B₂ 型 108s⁵；同类型才能用 K_sp 直接比较溶解度大小，不同类型要先换算成 s；g/100 g 水与 mol/L 的换算（稀溶液 100 g 水 ≈ 0.1 L）。
- 同离子效应：溶液中已有相同离子时溶解度大大降低（BaSO₄ 在 Na₂SO₄ 溶液中、CaCO₃ 在 Na₂CO₃ 或 CaCl₂ 溶液中）；计算时 0.5 + s ≈ 0.5；洗涤 BaSO₄ 沉淀用稀硫酸比用水损失少。
- 溶度积规则：离子积 Q > K_sp 有沉淀析出、Q = K_sp 饱和平衡、Q < K_sp 不饱和（沉淀溶解）；混合溶液要先算混合後的浓度。
- 分步沉淀：离子积先达到 K_sp 的先沉淀（Cl⁻ 与 CrO₄²⁻ 混合时 AgCl 先沉淀；Fe³⁺ 比 Mg²⁺ 先以氢氧化物沉淀）；K_sp 最小的硫化物（PbS）沉淀最完全。
- 沉淀溶解与转化：加酸消耗 CO₃²⁻、S²⁻、OH⁻ 使沉淀溶解（FeS、CaCO₃ 溶于酸，CaCO₃ 溶于醋酸）；钡餐用 BaSO₄ 不用 BaCO₃（胃酸会溶解 BaCO₃ 放出有毒的 Ba²⁺）；AgCl 加 KI 转化为更难溶的 AgI；锅垢 CaSO₄ 用 Na₂CO₃ 转化为 CaCO₃ 再用酸除去；含氟牙膏使羟基磷灰石转化为更难溶的氟磷灰石。
- 温度：溶解吸热的升温 K_sp 增大、溶解放热的升温 K_sp 减小。

## chap22 第二十二章：酸碱盐
- 三种酸碱理论：阿仑尼乌斯电离理论（水溶液中电离出的阳离子全部是 H⁺ 的是酸、阴离子全部是 OH⁻ 的是碱；KHCO₃ 是酸式盐、Cu₂(OH)₂CO₃ 是碱式盐；局限：不能解释 Na₂CO₃ 溶液、NH₃ 为何呈碱性及非水溶液）；布朗斯特—劳莱质子理论（给出质子的是酸、接受质子的是碱，共轭酸碱对相差一个 H⁺，H₂O、HCO₃⁻ 是两性物质；局限：没有质子参加的反应无法说明）；路易斯电子理论（接受电子对的是酸、给出电子对的是碱，如 Fe³⁺、SO₃、CO₂ 是路易斯酸）。
- 共轭酸碱对：HCl/Cl⁻、NH₄⁺/NH₃/NH₂⁻、H₃O⁺/H₂O/OH⁻、H₂CO₃/HCO₃⁻/CO₃²⁻；水与液氨的自偶电离（2H₂O ⇌ H₃O⁺ + OH⁻、2NH₃ ⇌ NH₄⁺ + NH₂⁻）。
- 强电解质（强酸、强碱、大多数盐，完全电离，用 →）与弱电解质（弱酸、弱碱，部分电离，用 ⇌）；导电性强弱要在浓度相同时比较。多元弱酸分步电离（K_a1 > K_a2 > K_a3，酸性主要由第一步决定）。
- 电离平衡的移动：加同离子（NH₄Cl 加入氨水、CH₃COONa 加入醋酸）抑制电离；加水稀释、升温（电离吸热）使电离度增大；加 HCl 于氨水促进电离。
- 电离度 α 与浓度有关（越稀 α 越大）；电离常数 K_a、K_b 只随温度改变，比较弱电解质强弱用 K 较好。近似式 K_a ≈ cα²、[H⁺] = cα（K < 10⁻⁴ 时可用）；同浓度、同体积的强酸与弱酸中和 NaOH 的量相同。
- 水的离子积 K_w = [H⁺][OH⁻]，25°C 时 1 × 10⁻¹⁴，升温 K_w 增大（高温时中性溶液 pH < 7，pH = 7 不一定中性）。pH = −lg[H⁺]、pOH、25°C 时 pH + pOH = 14。
- pH 计算：强酸混合（先算 n(H⁺) 再除总体积）、酸碱混合（先判断哪个过量）、强酸极稀时要考虑水的电离（10⁻⁸ M HCl 的 pH ≈ 6.98，不是 8）、由 pH 与 [A⁻]/[HA] 求 K_a。
- 中和滴定：等当点（定量完全反应）与滴定终点（指示剂变色）的区别；n(H⁺) = n(OH⁻)，x 元酸与 y 元碱 x c_a V_a = y c_b V_b；有效数字照题目给的位数。
- 滴定曲线与指示剂：强酸强碱等当点 pH 7、突跃约 pH 4–10（甲基橙、酚酞都可）；强酸滴弱碱等当点偏酸性，用甲基橙、甲基红；强碱滴弱酸等当点偏碱性，用酚酞；弱酸弱碱没有明显突跃。等当点不一定是 pH 7。指示剂是有机弱酸或弱碱（石蕊 HIn 红、In⁻ 蓝）。
- 盐类水解（见弱就水解、谁强显谁性）：CH₃COONa、Na₂CO₃、KF 显碱性；NH₄Cl、CuSO₄、Fe(NO₃)₃、Fe₂(SO₄)₃ 显酸性；NaCl、Na₂SO₄ 不水解显中性；弱酸弱碱盐看 K_a 与 K_b 的大小。要会写水解离子方程式（用 ⇌，CO₃²⁻ 分步水解只写第一步为主、不放出 CO₂）。
- Na₂CO₃ 溶液中 [Na⁺] > 2[CO₃²⁻]、[CO₃²⁻] > [HCO₃⁻] > [H₂CO₃]、[OH⁻] > [H⁺]；同浓度 Na₂CO₃ 碱性比 NaHCO₃ 强（越弱越水解）；NaHCO₃ 水解大于电离显碱性、NaH₂PO₄ 电离大于水解显酸性。
- 影响水解：越稀、越热水解程度越大；加酸抑制强酸弱碱盐水解（配 FeCl₃、CuSO₄ 溶液要加对应的酸）。应用：明矾净水、热纯碱溶液去油污、草木灰（K₂CO₃）不能与铵态氮肥混用。
- 缓冲溶液：弱酸 + 其盐（CH₃COOH/CH₃COONa）、弱碱 + 其盐（NH₃·H₂O/NH₄Cl）、多元酸的酸式盐与次级盐（NaH₂PO₄/Na₂HPO₄）；含抗酸成分与抗碱成分，加少量酸、碱或稀释 pH 几乎不变，但缓冲能力有限；血液、土壤都有缓冲作用。缓冲溶液的 pH 计算用同离子效应近似（[H⁺] = K_a × c酸/c盐）。

## chap23 第二十三章：电化学
- 原电池：化学能 → 电能，自发的氧化还原反应；负极（较活泼）失电子、发生氧化、电子流出；正极得电子、发生还原、电子流入。Zn–Cu（稀硫酸）：Zn 溶解、Cu 上冒 H₂；Zn–Cu（盐桥）：Zn | Zn²⁺ ‖ Cu²⁺ | Cu，Zn 棒变细、Cu 棒变粗。
- 构成条件：两个活泼性不同的电极（金属或石墨）、电解质溶液、闭合回路（导线 + 盐桥）；酒精不导电、两极相同或没有闭合回路都不能形成原电池。
- 盐桥：饱和 KCl 或 NH₄NO₃，阴离子移向负极区、阳离子移向正极区，保持溶液电中性；拿走盐桥电流停止。
- 电池符号：负极写左边，「|」表示相界面、「‖」表示盐桥；例 Cu | Cu²⁺ ‖ Ag⁺ | Ag、Cu | Cu²⁺ ‖ Fe³⁺, Fe²⁺ | Pt（溶液中的电对用惰性电极，正极不能用 Fe）。
- 化学电源：一次电池（锌锰干电池：Zn 负极、MnO₂ 正极、NH₄Cl；碱性锌锰电池负极 Zn + 2OH⁻ → Zn(OH)₂ + 2e⁻）、二次电池（铅蓄电池）、空气电池（4Al + 3O₂ + 6H₂O）。
- 铅蓄电池：放电 Pb(负) + PbO₂(正) + 2H₂SO₄ → 2PbSO₄ + 2H₂O，两极都生成 PbSO₄、硫酸浓度下降；充电是逆反应，PbSO₄ 在阴极变回 Pb、在阳极变回 PbO₂。
- 标准电极电势 E°（还原电势）：以标准氢电极为 0（1 M H⁺、1.01 × 10⁵ Pa、298 K）；还原电势越大越易得电子、氧化剂越强（F₂、MnO₄⁻、Cl₂、Br₂、Fe³⁺、I₂ …）；氧化电势与还原电势数值相等、符号相反。E° 与物质的量、方程式系数无关（乘系数不改变 E°）。
- 判断反应能否自发：E°cell = 负极氧化电势 + 正极还原电势（= E°正 − E°负）> 0 才能自发；例：Cu + 2Fe³⁺ 能反应（+0.43 V）、Cl₂ 能氧化 Br⁻、KMnO₄ 不能用盐酸酸化（会把 Cl⁻ 氧化成 Cl₂）。氧化剂的氧化性强于氧化产物、还原剂的还原性强于还原产物（Ce⁴⁺ > Fe³⁺ > Sn⁴⁺）。
- 电解池：电能 → 化学能，非自发反应；阳极接电源正极、发生氧化；阴极接电源负极、发生还原；阳离子移向阴极、阴离子移向阳极。电解池叫阴、阳极，原电池叫正、负极。
- 放电顺序：阴极看阳离子的还原电势（Ag⁺ > Cu²⁺ > H⁺ > … > Al³⁺、Na⁺、K⁺，活泼金属离子在水溶液中不放电）；阳极：活泼金属电极（Cu、Ag）本身先被氧化，惰性电极（Pt、石墨）时 S²⁻ > I⁻ > Br⁻ > Cl⁻ > OH⁻ > 含氧酸根、F⁻；课本规则：电位相差不大时浓者优先（浓 NaCl 溶液阳极放 Cl₂、稀 NaCl 溶液只电解水）。
- 常考电解：熔融 NaCl → Na + Cl₂；稀 NaCl、Na₂SO₄、KOH、H₂SO₄ 溶液 → 实际电解水（H₂ : O₂ = 2 : 1，Na₂SO₄ 溶液 pH 不变、KOH 溶液 pH 升高）；浓 NaCl → H₂ + Cl₂ + NaOH（氯碱工业，NaOH 在阴极区生成，用阳离子交换膜）；CuCl₂（浓）→ Cu + Cl₂；CuSO₄、AgNO₃（惰性电极）→ 金属 + O₂ + 酸，溶液 pH 下降；铜作阳极电解 CuSO₄ 溶液，阳极溶解、阴极变粗、溶液浓度不变。
- 应用：冶炼活泼金属（电解熔融 NaCl、MgCl₂、Al₂O₃ 加冰晶石；Al 太活泼不能用焦炭还原，Fe 可以）；电解精炼铜（粗铜作阳极、纯铜作阴极、CuSO₄ 溶液，Ag、Au 成阳极泥，Fe、Zn、Ni 留在溶液中）；电镀（镀层金属作阳极、被镀物作阴极、含镀层金属离子的溶液，溶液浓度不变）。
- 电解定律：n(电子) = Q/F，Q = It（库仑 = 安培 × 秒），F = 96500 C mol⁻¹；1 F 析出 1 mol Ag、2 F 析出 1 mol Cu、3 F 析出 1 mol Al；产生 1 mol O₂ 需 4 F、1 mol H₂ 或 Cl₂ 需 2 F；可由析出质量求通电时间、相对原子质量、离子电荷。
- 金属腐蚀：化学腐蚀（直接反应）与电化学腐蚀（形成原电池，较活泼金属作负极被氧化）；钢铁在中性或弱酸性水膜中吸氧腐蚀（正极 O₂ + 2H₂O + 4e⁻ → 4OH⁻），在酸性较强时析氢腐蚀（正极 2H⁺ + 2e⁻ → H₂）；铁锈 Fe₂O₃·nH₂O。
- 防护：覆盖保护层（油漆、搪瓷、电镀 Zn/Cr/Ni、烤蓝 Fe₃O₄）、牺牲阳极的阴极保护法（接上比铁活泼的 Zn，海轮外壳、管道）、外加电流的阴极保护法（钢铁接电源负极）、改变内部结构（不锈钢）。白铁（镀锌）镀层破损後铁仍受保护；马口铁（镀锡）破损後铁作负极反而腐蚀更快。

## chap24 第二十四章：核化学
- 核反应与化学反应的区别：核反应只与原子核的组成有关、元素会改变、放出的能量大几个数量级、不受温度和压强影响；化学反应只是核外电子重新排列、元素不变。
- 放射性：不稳定原子核自发放出射线（贝克勒尔发现铀、居里夫妇发现钋与镭）；原子序数大于 82 的天然元素都有放射性。
- 三种射线：α（He²⁺，⁴₂He，带 2 个正电荷，在电场中偏向负极，穿透力最弱、电离能力最强）；β（电子 ⁰₋₁e，偏向正极、偏转较大）；γ（高频电磁波，不带电、不偏转，穿透力最强、电离能力最弱）。穿透能力约 1 : 100 : 10 000。一种原子核不会同时放出 α 和 β；γ 常伴随 α、β 放出。
- 核的稳定性看中子数与质子数之比 n/p：原子序数 1–20 约为 1，越重的稳定核 n/p 越大（约 1.5）；¹²C 稳定、¹⁴C 有放射性。
- 衰变类型（质量数、核电荷数守恒）：α 衰变 Z−2、A−4；β 衰变 Z+1、A 不变（中子 → 质子 + 电子）；β⁺ 衰变 Z−1（质子 → 中子 + 正子）；电子俘获 Z−1；γ 衰变 Z、A 都不变。n/p 太大（在稳定带上方）做 β 衰变；n/p 太小做 β⁺ 衰变或电子俘获；Z > 82 多做 α 衰变。
- 衰变系列计算：先用质量数差算 α 次数，再用电荷差算 β 次数（²³⁸U → ²⁰⁶Pb 经 8 次 α、6 次 β）；位移定律：α 衰变在周期表左移两族、β 衰变右移一族。
- 人工核反应：¹⁴N + ¹n → ¹⁴C + ¹H、²⁷Al + ⁴He → ³⁰P + ¹n。同位素（¹³¹I 与 ¹²⁷I）不是同素异形体。
- 半衰期 T½：与温度、压强、化学状态无关；N/N₀ = (½)^(t/T½)；衰变常数 λ = 0.693/T½；放射强度与原子数成正比、与半衰期成反比；经过两个半衰期剩下 25%（不是 0）。¹⁴C 定年（T½ = 5730 年，信号剩 1/8 → 17 190 年）、²³⁸U–²⁰⁶Pb、⁴⁰K–⁴⁰Ar 测岩石年龄。
- 应用：考古与地质定年、医疗（⁶⁰Co、¹³¹I 治疗甲状腺、示踪原子）、工业（测厚度、探伤、查管道泄漏）、农业（育种、杀虫、抑制发芽）。
- 核能：核裂变（中子撞击重核如 ²³⁵U，放出更多中子形成链式反应；临界质量；原子弹是不受控的链式反应，核反应堆用控制棒吸收中子；核燃料约含 3% ²³⁵U；产生放射性核废料）；核聚变（轻核结合，需约 1 亿 °C，氢弹；放出能量更大、燃料易得、废料极少、没有临界质量）。
- 辐射防护：减少照射时间、增加与辐射源的距离、加屏蔽；医疗上选用半衰期短、能量低的同位素。

## chap25 第二十五章：有机化学
- 维勒加热氰酸铵（无机物）得到尿素（有机物），打破有机物必须来自生物体的观念；柯尔勃由无机物合成乙酸。
- 有机物一定含碳，但 CO、CO₂、碳酸盐、碳酸氢盐、金属氰化物属于无机物；有机物 = 烃（碳氢化合物）及其衍生物（烃的 H 被其他原子或原子团取代）。
- 有机物种类多的原因：碳链可长可短、可成链成环、可形成单双三键、常有同分异构体。
- 一般特性：大多可燃、多为共价化合物、多为非电解质、易溶于有机溶剂、熔点低易挥发、反应慢且常有副反应；但不是绝对的（CCl₄ 不可燃可灭火、羧酸是电解质、酒精易溶于水、乙烯使溴水褪色很快、醋酸与氨水反应生成强电解质醋酸铵使导电性变强）。
- 官能团决定性质：碳碳双键（烯）、碳碳三键（炔）、卤素原子（卤代烃）、羟基 −OH（醇、酚）、醛基 −CHO、酮基（羰基）、羧基 −COOH、酯基 −COO−、氨基 −NH₂（胺）、氰基 −CN（腈）、硝基 −NO₂；要能由结构辨认类别并命名（2-丙醇、2-丁烯、2-氯丙烷、丙醛、丁酮、乙酸甲酯、苯酚、4-甲基-2-戊烯）。易错：硝基与硝酸根、羟基与氢氧根不同。
- 通式：烷烃 CₙH₂ₙ₊₂、烯烃（与环烷烃）CₙH₂ₙ、炔烃（与二烯烃）CₙH₂ₙ₋₂；烷基 −R 为 CₙH₂ₙ₊₁。脂肪族（不含苯环）与芳香族（含苯环）。
- 研究方法：元素分析仪（组成元素）、红外光谱（官能团）、质谱仪（相对分子质量与结构）、核磁共振氢谱（等效氢的种类与个数比）。富勒烯 C₆₀（巴基球）。

## chap26 第二十六章：烷烃
- 来源：天然气（主要是甲烷）、石油；分馏按沸点分离：石油气 C₁–C₄、汽油 C₅–C₁₂、煤油 C₁₂–C₁₆、柴油 C₁₅–C₁₈、润滑油、沥青；越往塔顶分子越小、沸点越低、越易燃、越不黏稠。
- 裂化（无氧，大分子烃 → 小分子烃，提高汽油产量与品质；热裂化与催化裂化）、裂解（深度裂化，得乙烯、丙烯等化工原料）、重整（直链烃转为支链烃或芳香烃，提高辛烷值）；裂化没有固定产物，大烷烃裂成一个小烷烃和一个小烯烃（C₁₆H₃₄ → C₈H₁₈ + C₈H₁₆）。
- 结构：碳原子 sp³ 杂化、四面体（键角 109.5°），只有 σ 键（可绕键轴旋转）；NH₃ 也是 sp³ 但有一对孤对电子，键角 107°。易错：乙烷有 7 个 σ 键；烷烃的 C 是 sp³ 不是 sp²。
- 同系物：结构相似（官能团相同、通式相同）、组成相差一个或多个 CH₂；乙烷与环丙烷、丙烯与环丁烷不是同系物；相差 CH₂ 但官能团不同的（苯酚与苯甲醇）也不是。
- 同分异构体：分子式相同、结构不同；烷烃 n ≥ 4 才有（丁烷 2 种、戊烷 3 种、己烷 5 种、庚烷 9 种）；C₃H₆Cl₂ 有 4 种。会区分同素异形体、同位素、同分异构体、同一物质。
- IUPAC 命名：选最长碳链为主链（一样长选支链多的）→ 从靠近支链的一端编号、位次和最小 → 相同取代基合并（二、三）→ 不同取代基先简单後复杂（3-甲基-4-乙基己烷）。常见改错：没选最长链（2,4-二乙基戊烷应为 3,5-二甲基庚烷）、末端不能有甲基（1,1,4-三甲基己烷）。
- 物理性质：不溶于水；C₁–C₄ 气态、C₅–C₁₆ 液态、C₁₇ 以上固态；沸点随碳数增加而升高；同分异构体支链越多沸点越低（正戊烷 36°C > 新戊烷 9°C），对称性越高熔点越高。
- 化学性质：饱和、稳定，不与 KMnO₄、强酸、强碱反应，不能加成；燃烧生成 CO₂ 与 H₂O；隔绝空气高温分解（CH₄ → C + 2H₂）。
- 取代反应（光照，自由基链反应）：链引发 Cl₂ → 2Cl·（光把 Cl₂ 分裂成氯原子，不是离子）、链传递 Cl· + CH₄ → HCl + CH₃·、CH₃· + Cl₂ → CH₃Cl + Cl·、链终止（自由基两两结合，可生成 CH₃CH₃）。产物是混合物（CH₃Cl、CH₂Cl₂、CHCl₃ 氯仿、CCl₄）；每取代 1 个 H 消耗 1 个 Cl₂、生成 1 个 HCl，可由产物量算 Cl₂ 用量。溴代时较易取代含 H 较少的碳上的 H（丙烷主要生成 2-溴丙烷）。
- 环烷烃 CₙH₂ₙ（n ≥ 3）与同碳数单烯烃互为同分异构体；小环（三元、四元）不稳定，可与 H₂、Br₂、HBr 开环加成；五元、六元环稳定，与卤素取代；熔点比同碳数直链烷烃高。
- 燃烧计算：由 CO₂、H₂O 质量（碱石灰、浓硫酸增重）求 C、H、O 质量，再求实验式与分子式。

## chap27 第二十七章：烯烃
- 通式 CₙH₂ₙ（n ≥ 2），与环烷烃互为同分异构体；乙烯是平面分子，C 为 sp² 杂化，C=C 由一个 σ 键与一个 π 键组成；π 键较弱、易断裂，使双键活泼；C=C 不能自由旋转。C=C 键能比 C–C 大但不到两倍。
- 用途：乙烯是石油化工的基础原料、植物生长调节剂与果实催熟剂（用 KMnO₄ 吸收乙烯可延长保鲜）。
- 同分异构：碳链异构、位置异构、顺反异构（双键两端碳各连两个不同基团才有；同侧为顺、异侧为反，如顺-2-丁烯、反-2-丁烯；1-丁烯、2-甲基丙烯没有顺反异构）、官能团异构（与环烷烃）；C₅H₁₀ 共 10 种（烯烃 6 种含顺反、环烷烃 4 种）；C₃H₅Cl 的烯烃 4 种。
- 命名：选含 C=C 的最长链为主链、从靠近双键一端编号、标出双键位置（2-甲基-2-戊烯、4-甲基-1,3-戊二烯、顺-3-甲基-2-庚烯）。
- 物理性质：沸点随碳数增加而上升、比相应烷烃稍低；顺式沸点较高（有极性）、反式熔点较高（较对称）。
- 加成反应：加 H₂（Ni/Pt/Pd 催化）→ 烷；加 Br₂（溴的 CCl₄ 溶液红棕色褪去，用来检验与除去烯烃，生成 1,2-二溴乙烷）；加卤素水 → 卤代醇；加 HX、加 H₂O（H⁺ 催化）遵守马尔可夫尼可夫规则：H 加在含 H 较多的双键碳上（丙烯 + H₂O → 2-丙醇、(CH₃)₂C=CHCH₃ + HBr → (CH₃)₂CBrCH₂CH₃）。
- 氧化：冷的稀 KMnO₄ 碱性溶液 → 二元醇（紫色褪去、生成褐色 MnO₂ 沉淀，用来鉴别烯烃）；热的浓酸性 KMnO₄ 使双键断裂：=CH₂ → CO₂ + H₂O、=CHR → RCOOH、=CR₂ → 酮 R₂C=O（可由产物反推双键位置）。易错：除去乙烷中的乙烯不能用 KMnO₄（乙烯被氧化成 CO₂ 成为新杂质），要用溴的 CCl₄ 溶液或溴水。
- 加聚反应：n CH₂=CH₂ → 聚乙烯（单体、聚合度 n；聚乙烯中已没有 C=C）；丙烯加聚得聚丙烯。
- 烷烃主要发生取代反应、烯烃主要发生加成反应；烷烃不使溴的 CCl₄ 溶液或 KMnO₄ 褪色。
- 制法：石油裂解（最主要来源）；实验室乙醇与浓硫酸加热到 170°C 脱水（温度不够会生成乙醚；产物混有 SO₂，用 NaOH 溶液除去、品红检验）；卤代烷与 NaOH 的醇溶液共热发生消去反应（β-H 脱去，主要生成双键碳上取代基较多的烯烃）。
- 燃烧：烃燃烧生成 CO₂ 与 H₂O 物质的量相等 → C : H = 1 : 2（烯烃或环烷烃）；同温同压下由体积关系推分子式与混合气体组成。

## chap28 第二十八章：炔烃
- 通式 CₙH₂ₙ₋₂（n ≥ 2）；同碳数的单炔烃、二烯烃、环烯烃互为同分异构体（官能团异构）；炔烃从 n ≥ 4 起有位置异构、碳链异构（C₅H₈ 的炔烃 3 种、C₆H₁₀ 的炔烃 6 种）；炔烃本身没有顺反异构，二烯烃可以有（顺,顺-、顺,反-、反,反-2,4-己二烯）。
- 命名：选含三键的最长链、从靠近三键一端编号；同时有双键与三键时「烯」在前「炔」在後，位次和要最小，相同时让双键位次较小（4-乙基-1-庚烯-5-炔）。
- 乙炔：直线形，C 为 sp 杂化（两个 sp 轨域夹角 180°），C≡C 由一个 σ 键与两个 π 键组成；不是所有炔烃都是直线形（只有三键两端的原子在同一直线）。
- 物理性质：乙炔（电石气）纯净时无色无味、微溶于水、密度比空气略小；常温下碳数 ≤ 4 的炔烃为气态；炔烃沸点比相应的烷烃、烯烃稍高（1-戊炔 > 戊烷 > 1-戊烯），末端炔沸点低于三键在中间的异构体。
- 加成：完全加氢（Ni/Pt/Pd）→ 烷；林德拉催化剂只加一分子 H₂ → 烯；加 X₂ 先生成二卤代烯再生成四卤代烷（使溴的 CCl₄ 溶液褪色）；加 HX 遵守马尔可夫尼可夫规则（乙炔 + 2HI → 1,1-二碘乙烷）；加 HCl 生成氯乙烯（制 PVC）；在 HgSO₄、H₂SO₄ 催化下加水：乙炔得乙醛，其他炔烃得酮（2-丁炔 → 丁酮），中间经过不稳定的烯醇。
- 氧化：使 KMnO₄ 褪色（碱性有褐色 MnO₂、酸性无沉淀）；≡CH 被氧化为 CO₂、RC≡ 被氧化为 RCOOH，可由产物反推三键位置（A 氧化只得 CH₃COOH → 2-丁炔）。
- 金属炔化物：只有末端炔（≡C−H）能与银氨溶液生成白色炔化银、与铜（I）氨溶液生成棕红色炔化铜；用来区别 1-丁炔与 2-丁炔、鉴别乙炔。区别乙烷、乙烯、乙炔：先用银氨溶液（只有乙炔沉淀），再用溴水（乙烯褪色）。
- 制法：电石法 CaC₂ + 2H₂O → C₂H₂ + Ca(OH)₂（CaCO₃ → CaO，CaO + 3C →［高温］CaC₂ + CO；简易装置可控制反应开始与停止；产物含 H₂S、PH₃ 用 CuSO₄ 溶液除去；点燃前要验纯）；甲烷高温裂解。金属碳化物水解所得烃的 H 数 = 金属总价数（Al₄C₃ → CH₄、Mg₂C₃ → C₃H₄）。
- 燃烧：火焰明亮、带浓烟；氧炔焰温度约 3500°C，用于焊接与切割金属。乙炔二聚 → 乙烯基乙炔 → 加 HCl → 氯丁二烯 → 氯丁橡胶。

## chap29 第二十九章：芳香烃
- 苯 C₆H₆：由元素分析 C : H = 1 : 1、式量 78 得出；平面正六边形、键角 120°、六个碳碳键长完全相等（介于单键与双键之间）；C 为 sp² 杂化，六个未杂化 p 轨域形成离域大 π 键，所以苯比烯烃、炔烃稳定。凯库勒式无法解释苯难加成、邻二取代物只有一种。
- 物理性质：无色、有特殊气味的液体，沸点 80.1°C、熔点 5.5°C，密度比水小、不溶于水，良好的有机溶剂；易挥发、蒸气有毒（白血球减少）。苯萃取溴水後上层（苯层）变橙黄色。
- 化学性质：难氧化（不使酸性 KMnO₄ 褪色，燃烧火焰明亮带浓烟）、难加成（加 H₂ 需 Ni 加热得环己烷；光照加 Cl₂ 得六氯环己烷「六六六」，已禁用）、易取代。
- 取代反应：卤化（Fe 或 FeBr₃ 催化，溴苯；用 NaOH 溶液洗去溶解的溴；导管兼导气与冷凝回流、不插入液面以防倒吸；锥形瓶中出现 HBr 证明是取代不是加成）；硝化（先加浓硝酸再加浓硫酸，冷却後加苯，50–60°C 水浴，得硝基苯）；磺化（浓硫酸，约 80°C，苯磺酸）；傅–克烷基化（卤代烷 + AlCl₃ → 烷基苯）；傅–克酰基化（酰氯 → 苯乙酮）。
- 苯的同系物：通式 CₙH₂ₙ₋₆（只含一个苯环）；苯乙烯、萘等不是苯的同系物。
- 命名：一元取代（甲苯、氯苯、硝基苯、苯甲酸；苯乙烯、苯甲醇、3-苯基戊烷）；二元取代有邻、间、对三种异构体（1,2-、1,3-、1,4-二甲苯）；四溴苯有 3 种；苯基 −C₆H₅、苄基（苯甲基）。
- 甲苯：甲基使苯环邻、对位活化（硝化得邻、对硝基甲苯；加热、过量硝酸得 2,4,6-三硝基甲苯 TNT）；光照时卤代在侧链（苄基氯）、催化剂时卤代在苯环；苯环使侧链易被氧化：含 α-H 的侧链被热的酸性 KMnO₄ 氧化成 −COOH（甲苯 → 苯甲酸，其余侧链碳变 CO₂）——用来区别苯与甲苯。
- 烷基苯的物理性质：沸点比苯高、熔点比苯低（侧链使分子不易紧密堆积）。
- 来源：煤焦油分馏、石油催化重整与裂化；苯乙烯 8 个碳可共平面。

## chap30 第三十章：卤代烃
- 用途与例子：氯仿 CHCl₃（溶剂、曾作麻醉剂）、CCl₄（溶剂、灭火剂）、氟利昂 CF₂Cl₂（制冷剂，破坏臭氧层）、PVC、聚四氟乙烯（铁氟龙）、氯乙烷（运动场冷冻止痛，只能应急）、七氟烷（麻醉）、六六六（已禁用）。
- 分类：按卤素种类、卤原子数目、烃基（卤代烷、卤代烯、卤代芳烃）、与卤素相连碳的级数（一级、二级、三级）。
- 命名：以烃为母体、卤素作取代基；选含卤原子的最长链，靠近卤原子一端编号；烷基与卤原子并存时课本规定较优先的基团後列出（3-甲基-2-氯丁烷、4-甲基-2-氟-4-氯-3-溴庚烷）；不饱和卤代烃以烯、炔为母体（4-溴-1-丁烯、3-氯环己烯）；苄基溴、1-苯基-2-溴乙烷。
- 物理性质：不溶于水；沸点：碳数多的高、R−I > R−Br > R−Cl > R−F、同碳数支链少的高；一氯代烷密度小于水，溴代烷、碘代烷、多氯代烷（CCl₄）、溴苯密度大于水；卤原子越多可燃性越低。
- 取代（水解）：R−X + NaOH 的水溶液 →［加热］R−OH + NaX；与 NaCN（乙醇中）生成腈 R−CN（多一个碳，可水解成羧酸、还原成胺）；与 NH₃ 生成胺；与 NaHS、CH₃COONa 也能取代。卤代芳烃要高温高压才水解成酚。
- 消去：R−X + NaOH 的醇溶液 →［加热］烯 + NaX + H₂O（β-H 脱去）；邻二卤代烷与过量强碱的醇溶液生成炔。易错：NaOH 水溶液 → 醇（取代），NaOH 醇溶液 → 烯（消去）。
- 伍尔兹反应：2R−X + 2Na → R−R + 2NaX（增长碳链，如 2CH₃CH₂I → 丁烷）；两种卤代烷混用得三种烷烃的混合物。格氏试剂 R−MgX（干燥乙醚中由 R−X + Mg 制得）：遇水生成烷、与 CO₂ 作用後水解得羧酸、与甲醛得一级醇。
- 卤素检验：先与 NaOH 水溶液共热使卤原子变成卤离子，再加稀硝酸酸化，最後加 AgNO₃（AgCl 白、AgBr 淡黄、AgI 黄）；不能直接加 AgNO₃（C−X 不电离）。
- 制法：烷烃光照卤代（混合物）、醇与 HX 或 PX₃、PCl₅ 取代、烯或炔与 X₂、HX 加成（制 1,2-二溴乙烷用乙烯加 Br₂ 最好）、卤素互换（丙酮中用 I⁻ 置换 Cl、Br）。

## chap31 第三十一章：醇和酚
- 醇的分类：按羟基数（一元、二元、三元）；按连羟基的碳上烃基数（一级 RCH₂OH、二级 R₂CHOH、三级 R₃COH，如 1-丁醇一级、2-丁醇二级、2-甲基-2-丙醇三级）。饱和一元醇通式 CₙH₂ₙ₊₁OH（与醚同为 CₙH₂ₙ₊₂O）。
- 命名：选含 −OH 的最长链、从靠近 −OH 一端编号、标出羟基位置（3-甲基-2-丁醇、3-丁烯-2-醇、2,5-庚二醇、3-甲基环己醇、2-苯基乙醇）。
- 物理性质：醇分子间有氢键，沸点比式量相近的烷烃高；C₁–C₃ 醇与水任意互溶（与水分子形成氢键），碳数越多溶解度越小、沸点越接近相应烷烃（烃基阻碍氢键）。
- 氧化：强氧化剂（酸性 KMnO₄、K₂Cr₂O₇）使一级醇 → 醛 → 羧酸、二级醇 → 酮、三级醇不被氧化（可用来区别三类醇）；弱氧化剂（加热的 Cu 或 CuO）使一级醇只到醛、二级醇到酮。
- 脱水：乙醇与浓硫酸 170°C 分子内脱水生成乙烯（消去，需要 β-H，主要生成双键碳上取代基多的烯）；140°C 分子间脱水生成乙醚（取代）；三级醇一般不发生分子间脱水。乙醚：易挥发、易燃、麻醉剂、优良溶剂。
- 与活泼金属：2ROH + 2Na → 2RONa + H₂（醇钠是强碱）；钠与水比钠与乙醇反应剧烈（水中的 H 比醇羟基的 H 活泼）；醇、酚、羧酸都能与 Na 放出 H₂。
- 取代：与 HX 生成卤代烷；与 PX₃（3ROH + PX₃ → 3RX + H₃PO₃）、PCl₅（ROH + PCl₅ → RCl + POCl₃ + HCl，冒白雾，可鉴别醇）。
- 酯化：醇 + 羧酸 ⇌［浓 H₂SO₄、加热］酯 + 水，羧酸去羟基、醇去氢。会判断各反应断哪一个键（催化氧化断 O−H 与 α-C−H；分子内脱水断 C−O 与 β-C−H；与 Na 断 O−H；与 HX 断 C−O）。
- 制法：发酵（淀粉 → 麦芽糖 → 葡萄糖 → 乙醇，再蒸馏提高浓度）、乙烯与水加成（催化剂、加热加压）、卤代烷与 NaOH 水溶液水解。
- 重要的醇：甲醇（有毒，少量致盲；CO + 2H₂ → CH₃OH）、乙醇（燃料、溶剂、消毒）、丙三醇（甘油，黏稠有甜味、吸湿性、油脂皂化的副产品）。
- 酚：羟基直接连在苯环上（苯甲醇是醇不是酚）。苯酚：无色晶体、在空气中被氧化呈粉红色、熔点 43°C、室温时在水中溶解度不大，65°C 以上与水互溶；有毒、有腐蚀性，沾到皮肤用酒精洗。
- 苯酚的酸性（石炭酸，K_a ≈ 10⁻¹⁰）：极弱，不能使石蕊变色、不与碳酸盐（NaHCO₃）反应，但能与 NaOH 反应（浊液变澄清）；酸性 苯磺酸 > 苯甲酸 > 乙酸 > 碳酸 > 苯酚；苯酚钠溶液通入 CO₂ 析出苯酚（生成 NaHCO₃，不是 Na₂CO₃）。醇不与 NaOH 反应。
- 苯酚的取代：羟基使苯环邻、对位活化：与浓溴水在室温即生成 2,4,6-三溴苯酚白色沉淀（用于检验与定量）；也易硝化、磺化。显色反应：遇 FeCl₃ 溶液显紫色（检验酚；可用 FeCl₃ 一种试剂鉴别苯酚、乙醇、NaOH、KSCN 溶液）。
- 苯酚的工业制法：煤焦油、氯苯高温高压水解、异丙苯氧化法；用途：酚醛树脂（电木）、消毒防腐。

## chap32 第三十二章：醛和酮
- 通式：饱和一元醛与酮都是 CₙH₂ₙO（互为同分异构体，如丙醛与丙酮）；羰基 C=O 中 C、O 为 sp² 杂化，一个 σ 键一个 π 键，强极性；醛基 −CHO 一定在链端。
- 命名：选含羰基的最长链、从靠近羰基一端编号；醛基必在 1 号位不标号；酮要标羰基位置（3-甲基丁醛、2-甲基环己酮、苯乙酮、二苯基甲酮、5-甲基-3-庚酮）。
- 物理性质：醛、酮分子间不能形成氢键（没有 H 连在 O 上），沸点比相近式量的醇低、比烷烃高（醇 > 酮 > 醛 > 卤代烷 > 烷）；羰基 O 能与水形成氢键，低级醛酮可溶于水。甲醛水溶液（35–40%）叫福尔马林（防腐、保存标本）。
- 亲核加成（带负电的基团加在羰基 C 上）：加 HCN（碱催化）生成 α-羟基腈，水解得 α-羟基酸（增长碳链）；加醇（干燥 HCl）生成半缩醛、缩醛；加格氏试剂再水解：甲醛 → 一级醇、其他醛 → 二级醇、酮 → 三级醇（可由产物反推原料）。
- 还原：H₂/Ni 或 LiAlH₄ 使醛 → 一级醇、酮 → 二级醇；克里孟生还原（Zn-Hg、浓 HCl、加热）把羰基还原成 CH₂（得烷烃）。
- 氧化：醛易被氧化、酮不易——用弱氧化剂区别：托伦试剂（银氨溶液）RCHO + 2Ag(NH₃)₂OH → RCOONH₄ + 2Ag + H₂O + 3NH₃（银镜反应）；斐林试剂（CuSO₄ + 酒石酸钾钠 + NaOH，酒石酸根防止生成 Cu(OH)₂ 沉淀）在碱性中被醛还原成砖红色 Cu₂O。酮只在强氧化剂加热时断开羰基旁的 C−C 键生成羧酸（丁酮 → 乙酸、丙酸、CO₂）。
- 坎尼查罗反应：不含 α-H 的醛（甲醛、苯甲醛、(CH₃)₃CCHO）在浓 NaOH 中歧化成羧酸盐与醇。
- 羟醛缩合：含 α-H 的醛、酮在稀碱或稀酸中生成 β-羟基醛（酮），受热脱水得 α,β-不饱和醛（酮），再加氢得饱和醇（例：丙醛 + 苯甲醛 → 2-甲基-3-羟基-3-苯基丙醛 → 2-甲基-3-苯基丙烯醛）。
- 卤仿反应：含 CH₃CO− 的醛酮（乙醛、甲基酮如丙酮、丁酮、2-戊酮）以及含 CH₃CH(OH)− 的醇（乙醇、2-丙醇）与碘的 NaOH 溶液生成黄色 CHI₃ 沉淀；可鉴别乙醛与丙醛、2-戊酮与 3-戊酮。甲醛、丙醛、3-戊酮没有卤仿反应。
- 制法：一级醇氧化得醛（反应温度控制在醛与醇的沸点之间，让醛先蒸出，避免继续氧化成羧酸；或用 Cu 300°C 催化氧化）、二级醇氧化得酮；酰氯以 Pd/BaSO₄ 催化加氢还原得醛；格氏试剂与腈反应、水解得酮。
- 用途：甲醛（酚醛树脂）、丙酮（溶剂、指甲油去除剂、有机玻璃）、环己酮（锦纶）。
- 碳水化合物：多羟基醛或多羟基酮，常写作 Cₙ(H₂O)ₘ；分单糖、双糖、多糖；葡萄糖、果糖、麦芽糖、乳糖是还原糖（与托伦、斐林试剂反应），蔗糖不是；直链淀粉 α-1,4-苷键、支链淀粉另有 α-1,6 分支、纤维素 β-1,4-苷键、糖原分支更多；手性碳原子连有四个不同基团，产生对映（旋光）异构。最简式同为 CH₂O 的物质（甲醛、乙酸、甲酸甲酯、葡萄糖、果糖）含碳都是 40%。

## chap33 第三十三章：羧酸及其衍生物
- 羧基 −COOH；常见羧酸：乙酸、甲酸（蚁酸）、草酸（乙二酸）、乳酸（2-羟基丙酸）、苹果酸、柠檬酸、酒石酸、苯甲酸、水杨酸（2-羟基苯甲酸）；高级脂肪酸：硬脂酸（十八酸）、软脂酸（十六酸）、油酸（顺-9-十八烯酸，不饱和）。饱和一元羧酸与酯同为 CₙH₂ₙO₂。
- 命名：选含羧基的最长链、羧基碳为 1 号（3-甲基戊酸、2-甲基-3-羟基丁酸、3-甲基-2-丁烯酸、3-苯基丙烯酸、1,2-苯二甲酸）。
- 物理性质：分子间氢键使沸点高于式量相近的醇；C₁–C₄ 与水互溶，碳数越多溶解度越小，十二酸以上不溶于水。
- 酸性：弱酸，具酸的通性（能与 NaHCO₃ 放出 CO₂，苯酚不能）；甲酸 > 乙酸 > 丙酸；吸电子基使酸性增强：Cl₃CCOOH > Cl₂CHCOOH > ClCH₂COOH > CH₃COOH、F > Cl > Br 取代、卤素离羧基越近酸性越强（2-氯丁酸 > 3-氯丁酸）；苯甲酸 > 苯乙酸 > 乙酸。
- 衍生物（−OH 被取代，都含酰基）：酯（羧酸 + 醇，浓硫酸催化、可逆，酸去羟基醇去氢）、酰胺（羧酸铵盐受热脱水）、酰氯（与 PCl₃、PCl₅ 作用，冒白雾）、酸酐（P₂O₅ 脱水，二元酸可生成内酸酐）；甲酸没有酰氯与酸酐。羧酸被 LiAlH₄ 还原成一级醇。
- 制法：一级醇或醛氧化、芳烃侧链氧化（甲苯 → 苯甲酸）、烯烃被热酸性 KMnO₄ 氧化断键、腈水解（R−X → R−CN → RCOOH，增加一个碳）、格氏试剂加 CO₂ 再水解（增加一个碳）。
- 甲酸：分子中同时有醛基与羧基，所以能发生银镜反应、斐林反应、使 KMnO₄ 褪色（被氧化成 CO₂ + H₂O），是同系物中酸性最强的；工业由 CO + NaOH 制甲酸钠再酸化。
- 乙酸：食醋的成分；熔点 16.5°C，无水乙酸易结冰称冰醋酸；乙醇经醋酸菌氧化或乙炔 → 乙醛 → 乙酸制得。
- 乙酸乙酯的制备：浓硫酸作催化剂兼吸水剂（使平衡右移，但太多会使有机物炭化）；乙醇过量提高产率；饱和 Na₂CO₃ 溶液吸收产物（中和乙酸、溶解乙醇、降低酯的溶解度），导管不插入液面以防倒吸；用分液漏斗分离（酯在上层）；温度过高会生成乙醚副产物。
- 酯：命名「某酸某酯」（乙酸乙酯、甲酸乙烯酯、苯甲酸甲酯、乙酸苯甲酯）；低级酯有果香（乙酸戊酯香蕉油、丁酸乙酯凤梨油）、密度比水小、难溶于水；蜡是高级脂肪酸与高级一元醇的酯。
- 酯的水解：酸性条件可逆；碱性条件不可逆（生成羧酸盐），叫皂化反应；用 ¹⁸O 标记可证明酯化时羧酸去 −OH。也可由酰氯或酸酐与醇反应制酯；醛与醇不能生成酯。
- 油脂：高级脂肪酸的甘油酯；常温液态为油（植物油，不饱和成分多）、固态为脂肪（动物脂，饱和成分多）；R 越饱和熔点越高；天然油脂是混甘油酯的混合物，没有固定熔沸点；密度比水小、不溶于水。
- 油脂的反应：氢化（硬化，液态油加 H₂ 变固态脂肪，人造奶油；也可加卤素，植物油能使溴水褪色，不能用来萃取溴）；酸败（微生物水解或 C=C 被空气氧化成有臭味的低级醛酮；密封阴凉、加抗氧化剂）；水解（酸性得脂肪酸与甘油、碱性皂化得肥皂与甘油）。由皂化用碱量与加氢用量可求油脂式量与双键数。
- 肥皂与合成洗涤剂：高级脂肪酸钠（硬肥皂）、钾（软肥皂），有亲水的 −COO⁻ 与亲油的烃基；在硬水中生成 (RCOO)₂Ca、(RCOO)₂Mg 沉淀而失效；合成洗涤剂（烷基苯磺酸钠）在硬水中也能用、去污力强，但支链型不易被微生物分解会污染水源（改用直链型）。
- 氨基酸与蛋白质：天然蛋白质水解得 α-氨基酸（除甘氨酸外都是 L 型手性分子）；氨基酸有氨基（碱性）与羧基（酸性），是两性化合物、可形成内盐；肽键（酰胺键 −CO−NH−）；残基少于约 100 个为多肽、多于 100 个为蛋白质。

## chap34 第三十四章：高分子化合物
- 高分子（聚合物）相对分子质量约 10⁴–10⁶；天然有机高分子（蛋白质、淀粉、纤维素、天然橡胶）、合成有机高分子（塑料、合成纤维、合成橡胶）；无机高分子（玻璃、云母、石墨）。油脂、蔗糖不是高分子。
- 单体、链节（重复结构单元）、聚合度 n；聚合物是不同聚合度分子的混合物，式量只是平均值，没有固定熔点。
- 结构与性质：线型（直链如聚乙烯、PVC；支链如天然橡胶）有弹性、热塑性（可反复加热塑造）；体型（网状，如电木）没有弹性、热固性（受热不软化）；交联越多弹性越差、硬度越大。机械强度受聚合度、结晶度、分子间作用力影响；共价键连接、没有自由电子或离子，所以电绝缘；化学稳定、耐腐蚀，但不耐高温、易燃、易老化。
- 加聚反应：含 C=C 的单体加成相连，没有副产物；自由基机理（引发剂产生游离基 → 链增长 → 双基结合或歧化终止）。会由单体写聚合物、由聚合物找单体：PE（乙烯）、PVC（氯乙烯，不宜装食物）、PS（苯乙烯）、PP（丙烯）、腈纶（丙烯腈 CH₂=CHCN）、有机玻璃 PMMA（2-甲基丙烯酸甲酯）、聚四氟乙烯 PTFE（塑料王，耐腐蚀耐高低温）、聚偏二氯乙烯（CH₂=CCl₂）。
- 缩聚反应：单体含两个或以上官能团，同时生成水、HCl、CH₃OH 等小分子：涤纶（聚对苯二甲酸乙二酯，酯基相连；抗皱、不吸汗）、尼龙-66（己二酸 + 1,6-己二胺，酰胺键相连，分子间氢键使强度高、耐磨）、聚乳酸（可生物降解，免拆线手术缝线）、酚醛树脂（苯酚 + 甲醛，电木，热固性）、脲醛树脂（尿素 + 甲醛，电玉，易着色）。
- 天然橡胶：聚 2-甲基-1,3-丁二烯（异戊二烯）；胶乳加甲酸凝固；生胶易老化、不耐冷热、强度低，硫化（加 S 形成交联网状）後较坚韧；加炭黑提高强度与耐磨性、加防老剂延缓老化。
- 合成橡胶（都是加聚物）：顺丁橡胶（1,3-丁二烯，齐格勒-纳塔催化剂）、丁苯橡胶（1,3-丁二烯 + 苯乙烯）、氯丁橡胶（2-氯-1,3-丁二烯，耐油耐热）、丁腈橡胶（1,3-丁二烯 + 丙烯腈，抗油，做油管）；二烯烃 1,4-加聚後链中保留一个双键（−CH₂−CH=CH−CH₂−）。
- 塑料、合成纤维、合成橡胶的原料都来自石油；废塑料造成白色污染，3R（减量、再利用、回收）。
