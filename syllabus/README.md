# 官方考纲放这里

AI 出题脚本（[scripts/generate_questions.py](../scripts/generate_questions.py)）会自动找这个目录：

```
syllabus/biology.md      ← 生物考纲
syllabus/chemistry.md    ← 化学考纲
syllabus/physics.md      ← 物理考纲
syllabus/math.md         ← 高级数学（高数Ⅰ、Ⅱ）：课程标准整理成的文字档
```

**放了，出题就会依据官方考点；没放，就只依据章节标题出题**（质量差很多）。

档案格式不拘：**PDF 直接丢进来就行**（不必转成文字，脚本会自己抽），纯文字的 `.md`／`.txt`／`.pdf` 也都认得。
脚本看的是档案内容而不是副档名，所以就算你把 PDF 改名成 `.md` 也能正常运作。

## 为什么要你自己放？

董总的考纲网页**会拒绝程序自动访问**（对非浏览器的请求一律回 HTTP 403）。
既然网站明确表示不欢迎程序抓取，我们就不绕过它——由你用浏览器正常下载，再放进来。

## 怎么做（一科大约五分钟，做一次就好）

1. 用浏览器打开董总 UEC 的「高中考试纲要／评量规格」页面：<https://dongzong.my/uec/>
   → 统考资讯 → 考试纲要 → 高中
2. 下载该科的考纲 PDF
3. 把 PDF 存成 `syllabus/biology.md`（化学、物理同理），**不必转文字、不必排版**
4. commit + push

✅ 目前三科考纲都已放好（2026 年考纲，生物 5 页、化学 8 页、物理 5 页）。

**高级数学例外**：高数Ⅰ、Ⅱ的评量规格只写「评量内容请参阅《高级数学课程标准》」，范围在课程标准里（30 页，前面大半是素养通论）。所以 `math.md` 是把课程标准的 35 章内容标准、考试结构、公式表的符号写法整理成文字（约 8600 字），才放得进出题提示词的 12000 字上限。课程标准改版时，照新版表 4、表 8 改这份就好。

## 放什么内容最有用

优先贴这几类，出题质量差别很大：

- 每章的**学习目标／能力要求**（「能说明…」「能计算…」「能比较…」这类句子）
- **考试范围的边界**（哪些内容不考、哪些只要求认识不要求计算）
- 常用**符号、单位、术语**的规定写法
- 各章的**配分比重**（有助于让题目数量分配贴近真实考试）

## 顺带一提：其他公开授权来源

| 来源 | 授权 | 能不能自动抓 | 建议 |
|---|---|---|---|
| 董总官方考纲 | 官方公开文件 | ❌ 网站回 403 | 你手动下载放这里（如上） |
| [OpenStax](https://openstax.org) | CC BY-NC-SA 4.0 | 部分可以（其内容 API 被 robots.txt 禁止） | 可当**图表**来源；但内容是英文美国课纲，与统考对不上，且 ShareAlike 会连带要求衍生内容同样授权 |
| CK-12 | CC BY-NC | 同上 | 同上 |

所以这个项目真正该用的「公开来源」，是**官方考纲**——它不直接给题目，但它决定 AI 出的题准不准。
