# 草稿录题目录（drafts/）

把题目档丢进对应科目的子目录，推送到 `main` 分支后，GitHub Actions 会自动请 AI 录题、审题，
再开一个待审核 Pull Request：

- `drafts/biology/`   生物
- `drafts/chemistry/` 化学
- `drafts/physics/`   物理

## 收哪些格式

| 格式 | 说明 |
|---|---|
| 照片 `.jpg` `.png` `.webp` `.heic` | 拍清楚题干、选项、图表；含图的题会先放整页原图，请自己裁 |
| PDF `.pdf` | 扫描档或电子档都可以，18MB 以内 |
| Word `.docx` | 文字、表格、内嵌图片都会读；**萤光笔、底线、彩色字会保留**，用来标答案最方便 |
| PowerPoint `.pptx` | 每页的文字与图片 |
| 纯文字 `.txt` `.md` | 直接贴题目 |

旧版 `.doc` `.ppt`、Excel 等读不了，报告会写「请另存为 .docx」。

## 答案怎么给

- **最推荐**：在 Word 里用萤光笔（或底线、红字）标出正确选项，或在文末附答案表
- 没标答案也行，AI 会自己作答，但报告会注明「答案由 AI 作答」，请特别核对

## 自动审题做了什么

1. **格式**：题干不能空、选择题要恰好 A–D 四个选项、选项不能重复——不合格的题直接退回
2. **重复**：和正式题库、待审区里的题目比对，太像的退回
3. **文字**：夹英文虚词（例如「甘油 and 脂肪酸」）、残留转写标记、题号没去掉都会标出来；
   Word、PPT、文字档还会把录入的题干与选项和原档**逐字比对**，AI 改字、加字、漏字都标「⚠️ 和原档不一致」并写出差在哪
4. **答案复核**：AI 在看不到答案的情况下再做一次，和原档标的答案不一致就标「⚠️ 答案有疑」，排在最前面

被标出问题的题在 /dev 会展开给你改；什么都没标出的收成清单一键采纳。

## 题目里的图与高光

只取两样东西：**题目文字**与**题目要看的图**（页首页尾、页码、分数字样都不要）。

| 档案 | 图怎么来 | 高光（标答案）怎么认 |
|---|---|---|
| Word .docx | 直接取文件里嵌的图（含旧版 .doc 另存的） | 萤光、底色、底线、彩色字都会告诉 Gemini |
| PowerPoint .pptx | 直接取投影片里的图 | 萤光、底线、指定颜色的字（跟随主题色的不算） |
| 照片、PDF | Gemini 回报图在哪一页、哪个位置，自动裁出来；**一律标「请确认裁切」** | Gemini 直接看：涂萤光、圈起来、打勾、写上的字母 |

标在选项上的高光当答案；只标在题干几个字上（强调「不」「错误」）的当提醒。
做答题的图也会跟着进题库（例如看泌尿系统图写出各部位名称）。
裁得不好或抓不到的图，到 /dev 该题的「配图」换一张就好。

## 使用步骤

1. 用 GitHub 手机 App（或网页 Upload files）把档案上传到对应科目目录，直接 Commit 到 `main`。
2. 几分钟后会出现「🧪 AI 自动录题待审核」的 Pull Request，内文就是录题报告：录了几题、退回几题、哪些有问题。
   **一题都没录到**（例如全部是旧版 .doc）会改开一个 Issue 告诉你原因。
3. 看过报告就**合并这个 PR**——它只是把题目放进待审区，学生还看不到。
4. 到网站的 /dev「AI 录题待审」处理，按「采纳」才进正式题库。

处理成功的档案会直接删掉（git 历史里找得回来）；读不了或转写失败的留在原处，改好再推一次就会重试。

> 首次使用前，需要在 GitHub 仓库 Settings → Secrets and variables → Actions
> 添加 `GEMINI_API_KEY`，否则工作流会跳过录题。
